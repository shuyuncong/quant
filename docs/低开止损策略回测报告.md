# 低开与 5%–8% 止损策略回测报告

日期：2026-09-14

## 结论

本轮三个对照均未通过预注册研究筛选，不能替换当前研究基线的固定 8% 止损，也不授权修改生产 `config.yaml`、使用 Holdout 或投产。

- 固定 SL5：train、validation 候选级收益均恶化；viewed test 虽候选均值改善，但四仓组合相对 SL8 下降 11.41 个百分点。
- 弱市 SL5 / 其他 SL8：train、validation 候选级收益均为负；viewed test 四仓仅改善 0.10 个百分点，没有跨分片稳定性。
- 弱市低开 1.5% 开盘退出：validation 候选均值仅 +0.0502 个百分点且 IID bootstrap 区间跨零；viewed test 四仓下降 3.52 个百分点。

因此当前应继续保留 SL8。本文档提供了值得研究的条件变量，但没有提供足够证据支持直接改为 SL5 或启用低开开盘退出。

## 当前研究止损口径

- 固定止损：入场价下方 8%，即 `entry_price * 0.92`。
- 止盈：入场价上方 30%。
- 开盘已经穿越止损线时按开盘价成交，否则按止损价成交。
- 执行 T+1、同一日止损/止盈冲突时止损优先、封死跌停时延期退出。
- 本轮没有修改生产配置，也没有改变入场候选、卖点、持仓上限、仓位、费用或滑点。

## 冻结实验规则

没有扫描阈值，只比较以下预先固定的规则：

1. `baseline`：固定 SL8。
2. `fixed_sl5`：固定 SL5，仅用于判断结果是否只是来自整体收紧止损，不参与策略选择。
3. `regime_sl5_sl8`：目标交易日的前一指数交易日 `close < MA20` 时用 SL5，否则维持 SL8。
4. `weak_market_low_open`：前一指数交易日 `close < MA20`，且持仓日开盘相对个股前收低开至少 1.5% 时开盘退出；入场日不触发；封死跌停继续延期。其余情况维持 SL8。

总收益率：

| 分片 | SL8 baseline | 固定 SL5 | 弱市 SL5 / 其他 SL8 | 弱市低开 1.5% 退出 |
|---|---:|---:|---:|---:|
| train | -3.10% | +2.46% | -4.45% | -3.10% |
| validation | -13.82% | +0.74% | +4.21% | +1.38% |
| viewed test | +15.53% | +4.12% | +15.63% | +12.01% |

viewed test 相对 SL8 的组合变化分别为 -11.41、+0.10、-3.52 个百分点。validation 的组合改善没有在 viewed test 稳定复现；固定 SL5 的候选级与组合级方向还发生明显错配，说明结果受到持仓容量、提前释放资金和替换交易影响，不能只看组合总收益择优。

## 从参考文件可学习的变量

参考研究最有价值的不是某个固定阈值，而是以下条件变量：

- 市场状态：指数相对 MA20、短期收益和下行波动。
- 隔夜缺口：开盘相对前收的 gap 幅度。
- 交互项：市场状态 × gap，而不是单独使用 gap。
- 个股趋势：个股相对 MA20、趋势斜率；本轮没有加入主规则，避免一次改变多个条件。
- 前一日涨停/接近涨停：可能是独立行为组，但应单独预注册，并处理一字板可成交性。
- 波动与流动性：ATR、隔夜波动占比、成交额与开盘冲击成本。
- 可执行性：跌停锁死、T+1、费用和滑点。

参考文件的主要局限也必须保留：它使用全市场股票日而非本策略真实持仓，未计费用，开盘成交会排除极端不可成交样本，阈值存在事后选择；日线数据也不能直接证明 10:00–10:30 的分钟级退出建议。
