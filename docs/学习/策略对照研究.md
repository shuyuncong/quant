# 信号策略对照研究（买入 × 卖出 全组合）

> 数据窗口 2023-05-01 → 2026-10-04 ｜ 5007 只（前复权）｜ 结论基于同一份数据、同一套执行引擎，
> 只替换买入信号或卖出规则，不引入任何其它变量。

本文回答四个问题：**现在在用的策略是什么、优劣顺序是什么、每个策略的逻辑是什么、差异在哪**。

---

## 一、先给结论（TL;DR）

**现在最优的策略 = 年线趋势买入 + v1b 卖出。**

理由分两层，两层的答案是一致的：

| 层面 | 最优 | 关键数字 |
|---|---|---|
| 单笔信号质量（最可比） | **年线趋势 + v1b** | 单笔均值 +1.20%、盈亏比 3.24、PF 1.33，18033 笔 |
| 单笔收益 × 样本量 | **年线趋势 + fixed** | 单笔均值 **+2.02%**、胜率 **42.42%**、PF 1.43，18033 笔 |

年线趋势在**两种卖出规则下都是单笔层第一**（+2.02% / +1.20%），而日线零轴金叉在两种规则下都是垫底
（+0.09% / −0.88%）。这是本文最强的结论：**买入信号之间的差距，远大于卖出规则之间的差距。**

三条买入信号的排序（单笔均值，越大越好）：

```
年线趋势  (+2.02%)   ≫   零轴+底背离  (+1.43%)   ≫   日线零轴金叉  (+0.09%)
```

### 四个必须先说清楚的坑

1. **组合层数字受"先到先得"排序支配，不能当单一结论。** 同一批交易换一个 tie-break，
   年化能从 −16.93% 跳到 +33.07%。所以组合层我一律报**区间**，不报单点。
2. **零轴+底背离的组合层数字最好看（年化 25~30%、夏普 ~1.1、回撤只有 14~22%），但它只有 559 笔、
   只覆盖 749 个自然日。** 样本小 + 时间窗短，年化数字天然偏高，**不能与 18033 笔直接比**。
3. **组合层只抽到信号的一小撮，噪声很大。** 组合层成交数远小于交易样本数（如零轴金叉
   29513 笔交易只进了 192 笔组合成交），因为 4 个仓位装不下——组合层只反映"被仓位瓶颈
   放行的那一小撮"，不代表策略全貌。
4. **零轴金叉换 v1b 会显著变差**（+0.09% → −0.88%）。原因见第六节，这是本文最有实操价值的负面发现。

## 二、当前在用的策略是什么

系统里**同时存在三条买入信号、两套卖出规则**，但只有一部分真正在推送：

| 买入信号 | 代码位置 | 是否实盘推送 |
|---|---|---|
| 日线零轴金叉 + 回落确认 | `backtest_winrate.find_signals` | ✅ 推送（**唯一**推送的买入信号） |
| 年线趋势 A突破 / B回踩 | `strategy/yearline.py` | ❌ 不推送（研究池，`delivery` 恒为 0） |
| 零轴 + 底背离（四条件 AND） | `strategy/macd_divergence.py` | ❌ 不推送（研究展示池） |

| 卖出规则 | 参数 | 作用范围 |
|---|---|---|
| `fixed`（旧） | 止损 −8% / 止盈 +30% / 40 根超时 | **除零轴+底背离外的全部信号** |
| `v1b`（`divergence_trend`） | 止损 −8% / 日线顶背离 / 跌破年线 / 40 根超时（**无固定止盈**） | 仅 `macd_divergence_bottom` |

> ⚠️ **这里有一个现实落差**：v1b 是我们花了整轮研究选出来的最优卖出规则，但它的
> `apply_to_signal_types` 只写了 `macd_divergence_bottom`——**而这条买入信号恰恰不推送**。
> 也就是说，**v1b 目前对实盘行为的影响为零**；实盘真正在用的卖出规则还是 `fixed`。

## 三、三条买入信号的逻辑

### 3.1 日线零轴金叉 + 回落确认（`baseline`，实盘在用）

**核心思想**：在 MACD 零轴附近捕捉金叉，等价格回落确认后再进场，避免追高。

```
① MACD 金叉：DIF 上穿 DEA
② 零轴条件：DIF / DEA 距 0 轴不超过收盘价的 0.5%（zero_axis_tolerance: 0.005）
③ 回落确认：金叉后最多 5 根已收盘 K 线内出现回落
④ 加分项（门槛 min_confirmations = 0，即全部不满足也放行）：
   · 温和放量：当日量 / 20 日均量 ∈ [1.0, 2.0]
   · 突破 MA5 / MA10
   · 红柱连续放大
```

**优点**：信号极多（30546 个），覆盖广。
**缺点**：单笔均值 +0.09%、PF 1.02——**几乎等于没有边际**（扣掉手续费可能为负）。
门槛设成 0 是最大隐患：三个加分项一个都不满足也会买入。

### 3.2 年线趋势 A突破 / B回踩（`yearline`）

**核心思想**：年线是长期趋势的分水岭，只做站上年线的股票。

```
A 类（放量突破）：收盘站上年线，且成交量 ≥ 1.5 倍均量
B 类（回踩收复）：价格回踩年线附近（容差 2.5%）不破，随后收复
年线斜率：年线本身要向上          （MA_SLOPE_LOOKBACK 根内上行）
冷却期：  同类信号后 20 根内不重复发
```

**优点**：单笔均值 +2.02%、胜率 42.42%——**三条里最好**。且 18033 笔，样本量大，结论可信。
**缺点**：组合层不稳定（年化 −16.93% ~ +33.07%），因为信号多集中在少数时段，4 个仓位抢不过来。

### 3.3 零轴 + 底背离（`diverge`，四条件 AND）

**核心思想**：在底部区域捕捉"价格创新低但动能没创新低"的转折，并要求已站上年线。

```
① 零轴金叉：DIF 上穿 DEA，且 DIF/DEA 在 0 轴上下方邻近区
② 日线底背离：价格创新低但 MACD 负柱面积收缩（completed_negative_cycles 比较）
③ 放量：当日量 ≥ 1.5 倍均量
④ 年线以上：收盘 > MA250
四条同时满足才出信号（严格 AND，不做近似分层）
```

**优点**：单笔均值 +1.43%，且**组合层回撤最小（12.82% ~ 16.97%）**，夏普最高（~1.23）。
**缺点**：559 笔、578 个信号——**样本太小**，且集中在前复权窗口的后段。

## 四、两套卖出规则的逻辑

### 4.1 `fixed`（现行生产规则）

```
止损：−8%（盘中触发，止损优先）
止盈：+30%（到价即走）
超时：持仓满 40 根 K 线（在该根开盘卖出）
```

**问题**：+30% 的固定止盈会**砍掉大牛股**。实测揭示：在 `fixed` 下，
**超时退出的平均收益是正的（+3.97% ~ +5.85%），而止盈的平均收益被锁死在 +30% 附近**。
真正赚钱的单子往往是被止盈提前截断的。

### 4.2 `v1b` / `divergence_trend`（研究选出的最优卖出规则）

```
止损：−8%（盘中触发，止损优先）
顶背离：日线 MACD 正柱周期完成且面积收缩 + 更高高点 → 下一根开盘卖出
跌破年线：收盘 < MA250 → 下一根开盘卖出
超时：持仓满 40 根 K 线
没有固定止盈（这是与 fixed 最本质的区别）
```

**设计要点**：
- 顶背离是**单根触发**（只在正周期完成的那一根抬起），所以入场前形成的背离不会误杀掉新仓位。
- 所有退出信号都**收盘确认、下一根开盘成交**，不偷看未来。
- 保留 40 根超时是**必要的**：去掉超时后，移动止盈之类的规则会失去退出出口（12 方案研究结论）。

**实测代价**：回撤比 `fixed` 更大（零轴+底背离：22.5% vs 14.19%）。收益换来了，但回撤也变大了。

## 六、为什么 v1b 换到零轴金叉上会崩

这是整轮研究里**最有实操价值的一个负面发现**。

`v1b` 的核心是两条**趋势退出**：日线顶背离 + 跌破年线。它们成立的前提是
**买入信号本身已经隐含"这只股票处于长期上升趋势"**——零轴+底背离的第 ④ 条正是"收盘 > MA250"。

而日线零轴金叉**没有年线条件**。结果：

| 退出原因 | 年线趋势+v1b | 零轴金叉+v1b |
|---|---:|---:|
| `below_yearline`（跌破年线） | 10474 笔，均值 −4.43% | 4374 笔，均值 −2.47% |
| `stop_loss` | 1807 笔 | 11356 笔 |
| `timeout` | 3748 笔，均值 **+18.60%** | 4350 笔，均值 +17.58% |

零轴金叉 + v1b 里有 **11356 次止损**（占 38%），远超 fixed 下的 18025 次之外还叠加了趋势退出。
换句话说：**在一个没有趋势约束的买入信号上叠加趋势退出规则，等于让"跌破年线"变成一个随机
触发器**——它不区分"长期趋势走坏"和"日内正常回踩"，于是把大量本来会反弹的仓位提前砍掉。

**结论：卖出规则不能脱离买入信号的语义单独移植。** 必须先有趋势前提（年线条件），
趋势退出规则才有意义。

### 7.2 建议的行动顺序

1. **【最高优先】把年线趋势接上推送。** 它在两种卖出规则下都是单笔层第一，且 18033 笔、
   结论最可信。目前的状况是**最好的策略不推送，最差的在推送**。
2. **年线趋势用哪个卖出规则？** 若看重**单笔期望**用 `fixed`（+2.02%）；若看重
   **盈亏比和尾部**用 `v1b`（3.24，赢的更大）。我倾向 `v1b`——但**必须实测组合层**再定，
   因为它回撤更大（33.15% vs 30.09%）。
3. **【高优先】把日线零轴金叉降为 `observe_only`。** 单笔 +0.09%、PF 1.02，
   **扣掉手续费后基本为负**；且一旦误配 v1b 会直接变成 −0.88%。
4. **零轴+底背离继续留在研究池，不要上实盘推送。** 559 笔不足以下结论，需要先扩样本
   （放宽 `MIN_BARS` 或延长数据窗口）或做样本外验证。
5. **v1b 的作用范围不要扩到没有趋势条件的信号上。** 这是本文第四节验证过的硬结论。

## 九、局限性（必须知道）

1. **只有一轮样本。** 2023-05 → 2026-10 是单一市场环境，没有样本外验证。**年线趋势的
   +2.02% 可能包含这轮行情的特有红利。**
2. **样本量差距悬殊。** 29513 / 18033 / 559 三个量级，跨策略比较时必须特别注意置信区间。
3. **组合层受排序支配。** 年化区间宽度可达 50 个百分点（年线趋势：−16.93% ~ +33.07%），
   **任何单点组合数字都不可当作预期收益。**
4. **零轴+底背离的年化数字（30.10%）不应采信为预期收益**，它是短窗口 + 小样本 + 排序有利的叠加。
5. **未纳入闸门。** 加上每日交易次数闸门与仓位校验后，组合层数字会变（尤其是信号密集的
   零轴金叉和年线趋势，它们的候选被仓位瓶颈丢弃的比例很高）。
6. **未做参数敏感性扫描。** `vol_mult`、`tolerance`、止盈止损等参数只用了生产值，
   没有做网格寻优，因此不能排除"某条策略只是恰好踩中参数"。

## 附：研究过程中的关键修正

本轮研究推翻了两个直觉判断，记录下来避免重复踩坑：

1. **"v1b 是通用最优卖出规则" —— 错误。** v1b 只在有年线趋势前提的买入信号上最优，
   移植到零轴金叉上会把单笔均值打成负数（+0.09% → −0.88%）。
2. **"组合层年化收益可以排序策略优劣" —— 错误。** 组合层数字被 tie-break 排序严重污染，
   同一策略换个排序能差 50 个百分点。**判断策略优劣要看单笔层。**
