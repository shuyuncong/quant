# 短线与波动：可行性扫描（2026-11-05）

状态：**探索性扫描，不是投产授权**。数据、成本、执行口径与[基本面与动量研究](2026-11-05-基本面与动量研究.md)一致；本轮没有固化独立脚本，数字来自当前日线回测，若要投产需先固化为可复现脚本并预注册。

---

## 1. 先拆问题

“短线”和“波动”至少对应四种完全不同的策略，不能混在一起谈：

| 说法 | 实际含义 | 本轮能否验证 |
|---|---|---|
| 短线 | 周度/日度反转、5–20 日持有 | 能，日线足够 |
| 短线 | 日内/T+0/分钟级 | 不能，缺分钟级执行与成本模型；A 股 T+1 |
| 波动 | 低波因子、波动率过滤 | 能 |
| 波动 | 波动突破、波动扩张、放量突破 | 能 |
| 波动 | 波动率目标/降仓 overlay | 能近似，未做正式回测 |
| 波动 | 期权波动率风险溢价（卖 vol） | 不能，缺期权数据、保证金与尾部风险模型 |

下面只回答前三种可验证的部分。

## 2. 周度短线与波动扫描

股票池、样本、成本同主研究：300 只 mid/large cap，2018-01 → 2026-08，周度换仓，次日开盘成交，佣金 3bp + 印花税 10bp + 滑点 5bp，整手 100 股。

### 2.1 因子 IC（周度，预测下一周收益）

| 因子 | IC | ICIR | 正 IC 周占比 |
|---|---:|---:|---:|
| 5 日反转（`rev5`） | 0.032 | 0.20 | 58% |
| 20 日反转（`rev20`） | 0.043 | 0.25 | 59% |
| 低波（`lowvol`，20 日） | 0.053 | 0.26 | 61% |
| 5 日反转 + 低波 | 0.057 | 0.34 | 62% |
| 20 日反转 + 低波 | 0.058 | 0.34 | 65% |
| 20 日突破（接近/突破 20 日高点） | −0.008 | −0.05 | 49% |
| 波动扩张（20 日 vol / 60 日 vol） | −0.018 | −0.14 | 43% |
| 放量比（5 日量 / 20 日量） | −0.027 | −0.22 | 42% |

结论很直接：

- **反转和低波方向为正**，但 IC 只有 0.03–0.06，属于弱信号。
- **突破、波动扩张、放量比方向为负**；在这个池子里，“放量突破/波动扩张”是负期望，不是正期望。

## 3. 结论

1. **短线反转有弱 alpha，但周度换手把 alpha 吃掉了。** 最好的周度版本是 `rev5+lowvol + MA200`：Sharpe 0.641、交易胜率 53.7%，离 1.5/60% 很远。
2. **波动突破/波动扩张/放量突破是负期望。** 不要在这个池子里做“放量突破”或“波动扩张”作为主信号。
3. **低波是这组里最像因子的东西，但更适合月度/过滤器。** 月度 lowvol top20 胜率 58.5%，接近 60%，但 Sharpe 0.70、回撤 −36%；它更适合作为 `qvm_lv` 的一部分或风险过滤，而不是独立策略。
4. **月度 `qvm_lv` + MA200 仍是当前最优长多基线**：Sharpe 0.94、交易胜率 54.2%、回撤 −17.74%、换手 4.1x。
5. **如果“短线”指日内/T+0，本轮无法验证。** 需要分钟级数据、盘中执行、T+1 约束和更高的成本/冲击模型；当前仓库没有可复现的日内回测。

## 4. 如果还要继续，值得试的方向

按信息增益排序：

| 优先级 | 方向 | 关键改动 | 预期 |
|---:|---|---|---|
| P1 | 低换手短线 | 持有 20 日/月度，不做周度；反转 + 低波 + 质量 | 成本降到 2–4%/年，Sharpe 可能 0.6–0.9 |
| P1 | 波动率目标 overlay | 在月度 qvm_lv 上按 20 日 realized vol 缩放仓位，目标 8–12% | 可能改善 Sharpe/回撤，但预计 <1.2 |
| P2 | 全 A PIT 扩池 | 小盘/微盘 + 反转/低波 | 反转可能更强，但容量/流动性更差，必须计冲击成本 |
| P2 | 期权波动率风险溢价 | 卖 50ETF/300ETF 期权，保证金与尾部风险模型 | 高胜率、低常态波动，但尾部风险大；当前无数据 |
| P3 | 日内/T+0 | 分钟数据、盘口、执行模拟 | 当前不可验证；不建议在没有执行优势时投入 |

**不建议**：把周度反转/低波当成能到 1.5/60% 的主策略；或者在没有日内执行优势的情况下做 T+0。

---

## 5. 一句话

**短线反转有信号但没净收益；波动突破是负期望；低波是有效的过滤器，不是收益引擎。** 如果要做短线，先把换手降到月度、把成本压到 2–4%/年，再谈夏普；周度 40–80x 换手在这组数据上没有出路。
