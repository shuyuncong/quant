# 历史数据扩充与策略复验（2026-10-26）

状态：**研究记录，非投产授权**。生产 `config/config.yaml`、三策略默认参数、冻结样本与预登记哈希均未改动；
不接券商、不下单、不写数据库。

## 1. 目标与结论摘要

两件事：

1. 用免费、免注册的 BaoStock 把本地日线历史从 2023-05 中位起点扩到 2016-12，并补齐真实成交额与历史换手率
   （原 qfq 缓存约半数文件 `amount` 全 0，`volume_stability_risk_audit` 等因此无法验证流动性因子）。
2. 在扩样的独立缓存上复验两件事：市场闸门的跨窗口表现、固定“近 30 日均换手率 1%～5%”策略分支。

结论：

- 数据层可用且可复现；已验证 qfq 口径、股/元/% 单位、分页完整性与失败语义。
- 闸门仍是“降回撤为主、收益随窗口反复”，**不支持三策略统一加闸门**。
- 换手率过滤：零轴金叉 1 好 2 坏（不稳定）；年线趋势 **3/3 同向改善**，是唯一进入后续 holdout 的候选，
  但 3 个窗口符号检验 p≈0.125，且样本非 PIT，**不足以改生产**。
- 零轴＋底背离候选始终不足（4～7 笔/窗口），不下结论。

## 2. BaoStock 可行性实测（2026-10-26）

- 股票日线 `adjustflag=2`（前复权），指数 `adjustflag=3`（不复权）；日线最早 1990-12-19。
- 与既有 akshare 回填缓存对拍（`000001.SZ`，1,305 个重叠日）：close 最大差 0.0126，属前复权锚点漂移；
  `volume` 完全一致（单位：股），`amount` 为真实成交额（元），`turn=0.3437` = 0.3437%。
- 实测单只 6 年约 8～15s；耗时由股票只数决定，与年份跨度关系不大。
- SDK 约束：`login()` 期间 DNS/连接无超时；`send_msg` 吞异常后可能留下未成帧响应；
  分页失败时 `next()` 返回 False 且可能不更新 `error_code`。适配器因此：
  - 只在登录成功后对 SDK 自己的 socket 设 per-socket 超时，不改全局默认；
  - 每只股票核验 query 与分页两端的 `error_code`、返回字段、证券代码、请求日期、每行 `adjustflag`；
  - 末页恰为满页时判为可能截断并拒绝保存；
  - 任何失败丢弃当前连接，下一只重新登录，绝不把失败当 `no_data`。
- 分段获取：按 729 自然日切块，整只全部成功才写盘（跨除权/长历史大响应下仍完整）。

## 5. 复验设计（结果查看前冻结）

`output/backtests/_history_expansion_20261026/expanded_validation_plan.json` 固定了窗口、脚本、
arms、配置来源与判定门槛。要点：

- 闸门：5 窗口 × 3 策略 × 有/无闸门；archived 快照 + 各策略研究止损/方案（10%+`ladder_b`、
  3%+全清、6%+`ladder_b`），口径与 2026-10-13 对照一致。
- 换手率：3 窗口 × 3 策略 × 3 臂；样本快照默认退出（8%/30%/40 根超时）。
- 只允许比较 `available_baseline` 与 `turnover_1_to_5`；`all_signals` 混入缺失数据，仅作背景。
- 声称改善必须：覆盖率 ≥90%、候选/股票/信号日 ≥30/10/10，且方向跨窗口一致。

读法：

- 2018H2 闸门全关，空仓使零轴/年线避开 −17.6%/−15.5%，与 2022 的熊市保护方向一致。

- 回撤多数下降（2023H1 年线略升），仍是“减少暴露”，不是“挑出上涨日”。
- 该批样本与旧 1,300 只缓存、60 只轮次**不可混比绝对值**（同窗口零轴收益可差 18pp）。
