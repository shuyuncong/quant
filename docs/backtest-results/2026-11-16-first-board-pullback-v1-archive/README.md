## 一句话规则

首板放量涨停后，回调 **10%–25%** 但**不破首板日最低价**，量缩到首板日的 **60% 以下**且不超过 20 日均额；回调后 1–10 日内首次满足，**次日开盘买**；-5% 止损 / +10% 止盈 / 最多持 5 日。

## 完整规则（冻结，不再调参）

1. **首板**：T-1 涨停，且之前 20 个交易日无涨停。
2. **放量**：T-1 成交额 ≥ 前 20 日均额的 2.0 倍。
3. **价格/流动性**：T-1 收盘 ≥2 元；前 20 日均额 ≥2000 万元；历史 ≥250 根 K 线。
4. **回调**：T 后 1–10 个交易日内，首次出现收盘价相对 T-1 收盘回调 **10%–25%**。
5. **不破起点**：回调日收盘 ≥ 首板日最低价。
6. **缩量**：回调日成交额 ≤ 60% 首板日成交额，且 ≤ 前 20 日均额。
7. **入场**：回调日确认，次一交易日开盘买入；开盘涨停则放弃。
8. **出场**：买入后最多持有 5 日；收盘跌破 -5% 止损、收盘涨破 +10% 止盈，均次日开盘卖；到期第 5 个收盘后的下一开盘卖；跌停无法卖出顺延，最多 5 日。
9. **成本**：佣金 3bp/边、卖出印花税 10bp、滑点 10bp/边。
10. **组合**：100 万初始，单票 5%，最多 20 只；现金不计息。

## 数据与偏差

- 日线：BaoStock qfq 2016–2024 + 本地 qfq 2025–2026；2024-12-31 拼接，跨拼接交易剔除。
- 退市股：已并入 `cache/stock_pit/prices_delisted`，覆盖 **284 / 367** 只已知退市股；新增 219 只。
- 退市股使用 Eastmoney **不复权**日线，量从手换算为股；与 qfq 存在残余偏差。
- 无历史 ST 名单，ST 5% 涨停未识别。
- 无盘中分时；止损/止盈用日线收盘触发、次日开盘成交。
- 2026 只有 1–10 月；V1 结果不能外推到 2027。
