## PIT 口径

### 年报

`financial_abstract` 的列是**报告期**（如 `20231231`），不是公告日。年度长表按：

```
report_year = 2023
actual_disclosure = 2024-04-26   # 来自 stock_report_disclosure
statutory_deadline = 2024-04-30
pit_available = actual_disclosure.notna()
available_date = actual_disclosure
```

- 默认只使用 `pit_available=True` 的行；
- 没有实际披露日的行标 `False`，不用“默认 4 月 30 日”偷偷补；
- 如果某个实验明确选择“法定截止日回退”，必须单独标注，不能混入主口径。

年度长表的实际覆盖（`pit_available=True` 的指标行）：

| 报告年 | 指标行 | 有实际披露日的行 | 说明 |
|---:|---:|---:|---|
| 2019 | 8,353 | 6,297 | 2019 年披露表覆盖较低，缺失行不能用 |
| 2020 | 8,453 | 6,787 | |
| 2021 | 8,491 | 7,393 | |
| 2022 | 8,512 | 7,830 | |
| 2023 | 8,519 | 8,185 | |
| 2024 | 8,524 | 8,410 | 覆盖最好 |
| 2025 | 8,540 | 8,540 | 2025 年报披露日已纳入，PIT 可用 |

### 中证 1000

- `csi1000_current.csv` 是 **2026-11-05 快照**，不是 2019–2024 的历史成分。
- 用它做历史回测会产生**选择偏差**；只能作为“当前质量池”研究，或与现有“排名 801–1800”代理做对照。
- 历史 PIT 成分仍需付费源或指数变更重建。

### 业绩预告/融资融券

- 业绩预告用 `announcement_date`，不是报告期；
- 融资融券用 `trade_date`，只覆盖年末快照，不是每日全历史；
- 两者都只能作为辅助，不要当成完整日频序列。

## 缺口

| 缺口 | 状态 | 影响 |
|---|---|---|
| 历史 PIT 中证 1000 成分 | 不可得 | 无法做严格历史成分回测 |
| 审计意见（标准/非标） | 未补 | v3 九项排雷缺一项；Sina 只有“是否审计” |
| 监管立案/调查 | 未补 | 只能用公告文本/付费源 |
| 质押比例历史 | 失败 | 季度末接口返回空；只能试特定快照日 |
| 退市股日线 | 未补 | 退市名单有，行情源未验证 |
| 历史分钟/tick/盘口 | 不可得 | 不能复现盘中 9:31/10:00/10:30/14:00/14:50 |
| 总市值历史 | 未补 | 仍用流通市值/成交额换手率近似 |

## 复现命令

```bash
cd quant-python/signal_system

# 快速层：universe / disclosure / forecast / margin
# （pledge 历史接口当前不可用，单独执行会记录失败，不放进 fast）
python stock_pit_data.py --action fast --out cache/stock_pit --years 2019-2024

# 财务摘要：先 10 只试点
python stock_pit_data.py --action financial_abstract --out cache/stock_pit --limit 10

# 全当前中证 1000（约 45 分钟，视网络）
python stock_pit_data.py --action financial_abstract --all-current --out cache/stock_pit

# 重新生成年度 PIT 长表
python stock_pit_data.py --action normalize --out cache/stock_pit

# 三表原始数据试点（慢；仅在需要商誉/短借等明细时）
python stock_pit_data.py --action financials --out cache/stock_pit --symbols 000001,600000
```

产物校验：`cache/stock_pit/manifest.json` 记录每个文件的 SHA256、覆盖标记和错误列表；覆盖摘要见 [`backtest-results/2026-11-05-stock-pit-data/coverage.json`](backtest-results/2026-11-05-stock-pit-data/coverage.json)。

## 当前结论

- **能支撑的研究**：当前中证 1000 池的年度质量过滤、披露日对齐、业绩预告事件、融资融券辅助；可作为 v2/质量层的起点。
- **不能支撑的研究**：严格历史 PIT 中证 1000、完整 v3 九项排雷、盘中执行、退市股完整回测。
- **质量 A/B 已完成**：当前中证 1000 池，基线 32.02% CAGR / 1.383 Sharpe / −30.16%；宽松质量 29.66% / 1.212 / −28.35%；严格质量 11.41% / 0.588 / −35.54%。质量过滤未提升收益或 Sharpe，不投产。
- **下一步**：不调 ROE/ROA 阈值凑结果；若继续，先补历史 PIT 中证 1000 + 退市池，或把质量改成连续风险惩罚，预注册样本外。
