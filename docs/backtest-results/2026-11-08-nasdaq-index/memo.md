# 纳斯达克指数 / QQQ 趋势策略研究

日期：2026-11-08  
状态：**研究结论，不改变生产参数、不接券商、不下单**。  
入口：`quant-python/signal_system/us_index_study.py`  
产物：`summary.json`、`curves.csv`、`yearly.csv`、`trades_qqq_ma200.csv`  
测试：`quant-python/signal_system/tests/test_us_index_study.py`

## 0. 结论

1. **数据可得，且可交叉验证。** Yahoo chart API 能取到 QQQ、`^IXIC`、`^NDX` 从 2004-01-02 到 2026-11-06 的 5,749 根日线；FRED 的 `NASDAQCOM` / `NASDAQ100` 在 2006 年以后基本逐日一致（个别年份最大差 0.1–0.15%），2004–2005 最大相对差 1.33% / 1.51%，属于供应商历史修订/口径差异，不改变方向性结论。
2. **单独看纳斯达克，买入持有 QQQ 仍是最强收益基准。** 全期 CAGR 14.33%、Sharpe 0.73、最大回撤 −53.42%、期末 532 万（25 万本金）。MA200 把最大回撤降到 −26.42%，但 CAGR 降到 10.04%、Sharpe 0.70；Calmar 从 0.27 升到 0.38。**它是“降回撤”，不是“提收益/提 Sharpe”。**
3. **优势不显著。** MA200 与买入持有的配对 Sharpe 差为 −0.03，95% CI −0.31…+0.27，p=0.78；MA200 的 Sharpe 95% CI 0.30…1.11，买入持有 0.35…1.13，两者大幅重叠。
4. **分段看更像“熊市保险”。** 2004–2015 MA200 明显落后（CAGR 6.60% vs 10.65%，Sharpe 0.53 vs 0.59）；2016–2026 才略好（Sharpe 0.90 vs 0.88），但 CAGR 仍低 4.3pp。它避开了 2008、2022，也错过了 2009、2019、2023、2025 的修复段。
5. **对当前 A 股系统：不建议现在把“纳斯达克择时”作为独立策略投产。** 若目标是增加美国成长暴露，优先考虑 QQQ 买入持有作为战略卫星，并先做组合层叠加测试；若目标是风险控制，MA200 可作为 overlay 候选，但需要 FX、税、QDII/额度约束和 forward paper。现有 ETF 扩展研究的结论同向：公开资产配置控制组没有显著优于基线，不能因为“美股长期涨”跳过组合层验证。

## 1. 研究问题与边界

研究问题：

- 现有系统能否在不新增付费数据源的前提下拿到美国指数/ETF 日线？
- 简单趋势规则（MA200、12−1 动量、50/200 金叉、MA200 + 15% 波动目标）在纳斯达克上是否优于买入持有？
- 如果要做，应该用指数还是可交易 ETF？收益、回撤、换手和统计不确定性各是什么量级？

边界：

- **单资产、只做多、不做空、不加杠杆、不做日内。**
- 信号在日线收盘计算，下一交易日开盘成交。
- QQQ 使用 Yahoo `adjclose` 对 OHLC 做复权，近似总收益；指数使用价格收益，不含股息。
- 成本：滑点 5bp、佣金 0；现金收益 0%；未计股息税、FX、融资、QDII 溢价/额度、美国遗产税。
- 这是**单资产策略研究**，不是“把 QQQ 加进现有组合”的组合层结论。组合层需要另做叠加回测。

数据质量说明：

- FRED 与 Yahoo 在 2006 年以后基本逐日一致；2004–2005 的最大相对差为 `^IXIC` 1.33%、`^NDX` 1.51%，差异集中在 2004–2005，之后多数年份为 0。判断为供应商历史修订/口径差异，不是复权或时区错位。
- QQQ 的复权 OHLC 用 `adjclose/close` 同比例缩放，是总收益近似；严格的股息再投资应按现金流记账，但在 5bp 滑点和 22 年尺度下不改变结论。
- `^IXIC` 不是 QQQ 的跟踪指数；QQQ 跟踪 `^NDX`。因此同时给出 `^NDX` 作为更可比的价格收益对照。

读法：

- MA200 的保险在 2008/2022 有效；代价是修复年（2009/2019/2023/2025）大幅落后。
- 2005、2010、2011、2015、2016 是典型反复打脸年份：MA200 在这些年份的收益分别为 −9.28%、+1.78%、−11.41%、−6.21%、−3.51%，而买入持有为 +1.57%、+20.15%、+3.48%、+9.44%、+7.10%。
- 50/200 金叉只有 27 笔交易、换手 68.62x，CAGR 11.21%、Sharpe 0.71，和 MA200 的风险收益接近；如果在意换手/税务，它比 MA200 更干净，但仍不构成“优于买入持有”的证据。
- MA200 + 15% 波动目标把波动压到 12.65%，但 626 笔交易、换手 328.55x，CAGR 只有 8.85%；收益代价太大。

## 5. 成本压力与统计不确定性

MA200 成本压力（QQQ）：

| 滑点 | CAGR | Sharpe | 最大回撤 | 换手 |
|---:|---:|---:|---:|---:|
| 0bp | 10.39% | 0.72 | −25.75% | 330.53 |
| 5bp | 10.04% | 0.70 | −26.42% | 314.91 |
| 10bp | 9.69% | 0.68 | −27.09% | 300.13 |
| 20bp | 9.00% | 0.64 | −28.41% | 272.93 |

- 成本从 0 到 20bp，CAGR 下降约 1.39pp，Sharpe 从 0.72 降到 0.64；结论方向不变，但 MA200 对成本敏感度高于买入持有。
- 这里只计滑点/佣金，未计资本利得税、股息预扣税和 FX 点差；真实净收益会更低。

Block bootstrap（10,000 次，block=20，QQQ 日收益）：

| 指标 | 值 |
|---|---:|
| MA200 Sharpe | 0.701 |
| MA200 Sharpe 95% CI | 0.296 … 1.110 |
| 买入持有 Sharpe | 0.732 |
| 买入持有 Sharpe 95% CI | 0.352 … 1.129 |
| 配对 Sharpe 差（MA200 − BH） | −0.031 |
| 配对差 95% CI | −0.311 … +0.266 |
| 配对差 p 值（双侧） | 0.782 |

**结论：没有统计证据表明 MA200 的 Sharpe 高于买入持有。** 单序列的 deflated Sharpe 很高（0.999）只说明“这条规则的 Sharpe 不太像纯噪声”，不能替代“相对于买入持有是否更好”的配对检验；两者不是同一个问题。

## 6. 对当前系统的含义

### 6.1 不建议投产的部分

- **不建议把“纳斯达克 MA200 择时”作为独立策略加入生产。** 它在全期没有提高 Sharpe，收益显著落后买入持有；只有在“必须把最大回撤压到 30% 以内”的约束下才有讨论价值。
- **不建议用 `^IXIC` 做可交易标的。** 它是价格指数，不可直接交易；QQQ 跟踪的是 `^NDX`，两者不能混用。
- **不建议现在改 `config/config.yaml`、ETF 轮动参数或三策略口径。** 本文是单资产研究，没有组合层证据。

### 6.2 如果要做美国成长暴露

优先级从高到低：

1. **QQQ 买入持有作为战略卫星**：逻辑最简单、成本最低、没有择时参数；先做“现有 A 股 ETF 组合 + QQQ 固定权重”的组合层回测，再谈比例。
2. **QQQ + MA200 作为风险控制 overlay**：只在明确接受“用 4pp 左右 CAGR 换 12–25pp 回撤下降”的前提下考虑；需要 forward paper 验证 2005/2010/2015 类型的反复打脸是否可承受。
3. **多资产 dual momentum（QQQ/SPY/TLT/GLD 等）**：本文没有测；如果要做，必须预注册规则、限制参数搜索，并用同一套 block bootstrap 和成本口径。

### 6.3 现实约束

- **准入**：内地账户直接买 QQQ 通常需要 QDII/海外券商/港股通替代品；QDII 有额度、溢价和申赎限制，不能假设按净值成交。
- **税**：美国上市 ETF 的股息通常有预扣税（中美国税收协定下可能 10%，实际按券商/税务处理）；本文未扣。美国遗产税对非居民的美国 situs 资产有门槛，持有金额较大时需要咨询税务顾问。
- **FX**：QQQ 以美元计价，人民币投资者承担 USD/CNY 波动；本文未做汇率对冲或换算。
- **交易制度**：美股 T+1 结算、无 A 股涨跌停、盘前盘后流动性差异；本文只用日线开盘价，未模拟盘前/集合竞价。
- **数据**：Yahoo 适合研究，不是生产级数据源；投产需要稳定授权源或券商 API，并保留 manifest/缓存。

## 7. 下一步（若继续）

1. **组合层叠加**：现有 ETF v5.1（40/35 + 回填、vol10）与 QQQ 固定权重（例如 10%/20%，月度或季度再平衡）做同区间、同成本回测；看组合 Sharpe、最大回撤、与沪深300/黄金/国债的相关性，而不是只看 QQQ 单资产。
2. **预注册 dual momentum 研究**：QQQ/SPY/TLT/GLD 四资产、12−1 动量、月度调仓、同一成本；先写规则再跑，避免参数搜索。
3. **forward paper**：若组合层结果支持，至少 3–6 个月纸面跟踪，确认数据、FX、税、执行和回撤承受度。
4. **不改变生产**：在上述证据齐备前，`config/config.yaml`、ETF 轮动参数和三策略口径保持不动。
