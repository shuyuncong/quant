# 首板放量涨停 + 缩量回调（2026-11-10）

状态：**研究完成，结论 reject。不进入生产、不接纸面、不自动交易。**

## 1. 口径

首次运行前固定，不按结果调参：

| 项 | 取值 |
|---|---|
| 股票池 | 本地 qfq 日线，排除北交所（4/8/92）；5145 个代码 |
| 历史长度 | 信号日前至少 250 根日线 |
| 流动性 | 涨停日前 20 日日均成交额 ≥2000 万元；涨停日收盘价 ≥2 元 |
| 首板 | 涨停日之前 20 个交易日内没有涨停 |
| 放量 | 涨停日成交额 ≥ 前 20 日日均成交额的 2.0 倍 |
| 涨停 | 收盘涨幅达到对应板涨跌停幅度，且收盘 = 最高价（封住） |
| 缩量回调 | 涨停后 1–3 日内，首次出现：收盘低于涨停日收盘、回撤 ≤8%、成交额 ≤0.6×涨停日成交额、且 ≤涨停日前 20 日均额 |
| 入场 | 回调日收盘确认，次一交易日开盘买入；开盘涨停则放弃 |
| 出场 | 最多持有 5 个交易日；收盘跌破 -5% 止损、涨破 +10% 止盈，次日开盘卖出；到期后下一开盘卖出；跌停无法卖出则顺延，最多 5 日 |
| 成本 | 佣金 3bp/边，卖出印花税 10bp，滑点 10bp/边；压力测试 20bp/边 |
| 组合 | 100 万初始资金，单票 5%，最多 20 只，同日候选按放量倍数排序；无杠杆，现金不计息 |

持有期 5 日是主口径；另外跑 1/3/10 日作为敏感性，不据此挑最优。

数据：BaoStock qfq 2016–2024 + 本地 qfq 2025–2026。2024-12-31 拼接处不做跨口径交易；ST 历史名单缺失，ST 的 5% 板实际上不会被识别。

| 出场 | 笔数 | 净均值 | 胜率 |

27.3% 的交易触发止损，只有 7.5% 触发止盈；到期组接近打平。少量大止盈不足以覆盖止损和交易成本。

## 5. 结论

1. **不是成本问题。** 扣费前平均每笔已经是 -0.37%；10/20bp 滑点只是把负值放大到 -0.73%。
2. **不是持有期问题。** 1/3/5/10 日持有期的 gross 和净均值全部为负。
3. **不是单一年份问题。** 2019–2024 逐年扣费均值全部为负，2025 仅约打平，2026 再度转负。
4. **组合曲线同样为负。** 主口径年化 -2.83%、Sharpe -0.810、最大回撤 -23.75%；20bp 压力年化 -3.72%。且平均股票暴露只有 6.92%，说明信号频率/持有期使资金利用率很低，放大仓位不会改善负期望。
5. **“首板 + 放量 + 缩量回调”没有表现出可交易的短线反转 edge。** 更常见的路径是回调后继续走弱，止损组贡献了主要亏损。

**判决：reject。不继续调放量倍数、缩量比例、回撤上限、持有期或止损止盈参数。**

## 6. 限制

- “首板”按前 20 日无涨停定义；更短/更长的首板间隔是不同假设。
- 放量用成交额，不是分时量比或封单量；没有盘口、封单、炸板数据。
- 没有历史 ST 名单；ST 5% 板无法按 10%/20% 规则识别。
- 2024-12-31 数据拼接处已避免跨口径交易，但拼接前后复权基准仍可能有细微差异。
- 事件交易允许重叠，t 值不是独立样本的严格显著性检验。
- 2025–2026 已被其他研究查看，只能算时间 holdout，不是干净 OOS。
- 组合按 5% 固定名义仓位、最多 20 只，未做行业/市值中性化。
