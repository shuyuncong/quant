# 三策略止盈分批减仓 —— 熊市区间核验（2026-10-12）

> ⚠️ **本档的第一结论是"原定的 2018/2022 熊市验证无法执行"**，不是"熊市下分批减仓有效/无效"。
> 本地行情库不覆盖那两段，任何声称覆盖了它们的结论都是编的。下文给出可执行范围内的
> 最强替代证据（2024Q4，指数 −3.95%），并明确它的局限。

## 一、为什么 2018 / 2022 跑不了（实证，非推断）

| 数据源 | 覆盖范围 | 结论 |
|---|---|---|
| `cache/daily_history/*_qfq.pkl`（5008 只） | 起点中位数 **2023-05-18**，最早 2022-12-26 | 0 只覆盖 2018；0 只覆盖 2022 |
| `cache/index_000001_sh.pkl`（上证指数） | 2021-09-16 起 | 2018 无数据；2022 仅指数、无成分股 |
| 所有长历史模块的 `HISTORY_DIR` | 同指 `cache/daily_history`（`backtest_winrate.py:62` 定义，5 处引用） | 无第二个长历史数据源 |

2018 全年 **本地一行数据都没有**。2022 年指数在，但 5008 只个股的行情全部起于 2022-12-26，
没有任何一只具备回测所需的 270 根（MA250 + 20 日斜率）预热日线。

**预热约束进一步锁死区间**：三策略要求"首个交易日前 ≥ 270 根已收盘日线"，
而上表显示第 270 根日线的中位数落在 **2024-06-27**（最早 2024-04-08）。因此：

| 区间 | 指数涨跌 | 可跑标的 | 能否作为熊市样本 |
|---|---|---|---|
| 2018 | — | 0 | ❌ 无数据 |
| 2022 | −14.95% | 0 | ❌ 仅指数，无个股 |
| 2023H2 | −8.29% | **0**（预热不足） | ❌ 区间在，样本不在 |
| **2024Q4** | **−3.95%** | **4739 / 5008** | ✅ 唯一可跑的下跌区间 |
| 2024H2 | +11.92% | 4647 | 已用作上一轮样本外（上涨） |
| 2025H2 | +14.78% | 4820 | 上涨 |

结论：**数据能支撑的最早下跌区间是 2024Q4**，且它只有 61 个交易日，
跌幅（−3.95%）远小于 2022（−14.95%，本地指数可核）。它**不能替代**真正的熊市验证。

## 三、能说什么、不能说什么

**方向与 2024H1/H2 一致的（三条样本互相印证）：**

1. **年线趋势在下跌区间同样是分批减仓有害**：`none +2.37%` 是唯一正收益，四个分批方案全部为负
   （最好 `trailing_a +0.49%`，阶梯形态 −2.14% / −3.90%）。这与 H1/H2 的结论方向一致，
   现在有三个区间支持"年线趋势不适合分批减仓"。
2. **零轴＋底背离在下跌区间仍是阶梯形态占优**：`ladder_b +0.45%` / `ladder_a −0.48%` vs
   基线 −6.04%，胜率同时从 20% 升到 33%~36%。方向与 H1/H2 一致。

**与 2024H1/H2 冲突的：**

3. **日线零轴金叉的"半仓 + 尾仓保本止损"在下跌区间不再是好选择**：
   它在 H1/H2 两段都是最优或接近最优，本区间却是**五个方案里最差**（−21.65%，比基线还低 1.47pp，
   回撤同时从 20.18% 升到 21.78%）。保本止损把尾仓提前打掉，随后反弹时已不在场内。
   这直接推翻了"hybrid_b 对零轴金叉最稳"的普适性。
4. **移动止盈单独使用在日线零轴金叉上反而最好**（−6.28% vs 基线 −20.18%，回撤 20.18%→12.35%），
   而它在 H1 是巨亏（−11.36%）、H2 是最优（+14.60%）。三个区间三个结论，**不可作为默认形态**。

> 针对日线零轴金叉的完整机制归因（含 `none` vs `hybrid_b` 的 equity 对账、
> 保本止损为何在下跌区间反转、以及 `trailing_a` 为何形态依赖）见
> [2026-10-12 日线零轴金叉减仓方案重分析](2026-10-12-日线零轴金叉减仓方案重分析.md)。

**不能说的：**

5. **这不是熊市验证**。−3.95% / 61 个交易日，而 2022 是 −14.95% / 242 个交易日
   （本地指数数据可核），2018 的本地数据不存在、无法给出可核数字。两者不在一个量级；
   样本内已平仓仅 10~17 笔，且零轴＋底背离的 `max_drawdown` 在五个方案间**完全相同
   （8.59%）**——说明这些数字由入场与止损侧主导，不是止盈方案可分出来的差异。
6. **任何"分批减仓在熊市有效/无效"的表述都超出现有证据。**

## 四、结论与后续

- **默认参数保持关闭**（`risk.exit_plan: null`、`risk.strategy_exit_plan` 三项 `null`）不变。
  本轮没有产生任何投产依据：唯一支持的普适结论是"年线趋势不适合分批"，那可以用**保持该策略不分批**
  表达，不需要改默认。
- **要真正回答"熊市下分批减仓是否成立"，必须先补数据**，二选一：
  1. 拉取 2018/2022（或至少 2022 全年）的个股日线进 `cache/daily_history`，
     并接受 MA250 预热会再吃掉前 270 个交易日（即 2022 有效区间实际从 2023 年中才开始，
     **仍然覆盖不到 2022 的下跌段** → 实际需要拉到 2018 年前后的数据）；
  2. 改用不需要 270 根预热、或预热更短的策略变体单独验证，但那会同时改动策略口径，
     不再是"只改止盈"的单变量对照。
- 在补数据之前，本主题**不应再重复回测**：已有三个区间（2024H1 / 2024H2 / 2024Q4）的结论互相矛盾，
  再跑同一数据范围内的其他切分只是重复抽样。

## 复现

```bash
cd quant-python/signal_system
python scale_out_take_profit_study.py --period oos \
  --start 2024-10-01 --end 2024-12-31 --workers 6 \
  --plans none ladder_a ladder_b hybrid_b trailing_a \
  --out-json output/backtests/scale-out-take-profit-250k-2024q4/comparison.json
```

`--period oos` 会先用本地前复权缓存在 `output/backtests/scale-out-take-profit-250k-2024q4/sample-2024-10-01-2024-12-31/`
烤出一份与冻结包同构的样本（可中断续跑），本轮样本构建约 55 分钟（4739 只，
269 只因预热不足被剔除，剔除原因见 `comparison.json` 的 `sample.universe`）。
`parity_vs_archive` 在本模式下为 `checked: false`——样本外区间不与 H1 归档核字段，属预期。

原始产物：`docs/backtest-results/2026-10-12-three-strategies-scale-out-bear-window/{comparison.json,metrics.csv}`。
