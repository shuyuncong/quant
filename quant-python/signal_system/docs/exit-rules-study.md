# 卖出规则研究（2023-05 ~ 2026-10）

**结论**：零轴+底背离研究池采用 **v1b** —— `止损 −8% + 日线MACD顶背离 + 跌破年线 + 持仓超时40根`，
并**取消固定 +30% 止盈**。

**生效范围**：`backtest.exit_rules.mode = "divergence_trend"`，通过
`apply_to_signal_types: ["macd_divergence_bottom"]` 限定只作用于该研究池；
生产 MACD 池、缠论买点、年线池保持 `fixed`。

## 样本与口径

- 标的：5007 只（`cache/daily_history/*_qfq.pkl`，前复权）
- 信号：零轴金叉 + 底背离 + 放量≥1.5 + 年线以上（四条件 AND），559 笔成交
- 成交：次日开盘买入、T+1、涨跌停限制、佣金 0.03% / 印花税 0.1% / 滑点 0.05%
- 组合：10 万本金、最多 4 只、单只 25%
- **组合收益一律报 4 种排序（symbol_asc / symbol_desc / hash / rotate）的区间**，
  因为 559 笔信号只有约 90 笔能被 4 个仓位吃下，"先到先得"会主导单点数字

## 四条被数据证实 / 证伪的判断

1. **"跌破MA20"是元凶，且放宽无效 → 应直接删除**
   - 原版（v0，含 MA20）：+1.44%
   - 放宽为连续 3 天（v3）：+2.12%，组合中位仅 +15.6%
   - 放宽为"跌破且 MACD 死叉"（v3b）：**+1.28%**，比原版更差
   - **直接删掉（v1）：+2.70%**，仅次于 v4c

   原因：MA20 是趋势的早期警报，改成 3 天或加死叉只是把卖出推迟几天，而延迟的
   几天恰好是下跌最猛的阶段——多亏几个点才走。在止损+超时已存在时，这条线整体多余。

2. **保留 40 天超时是正确的**
   v1（有超时）+2.70%/PF1.52 vs v0（无超时）+1.44%/PF1.34；引擎口径下超时单
   贡献 +3202pp，是最大利润来源。它同时给震荡票一个资金出清点。

3. **移动止盈方向对，但必须配超时、且不能太紧**
   - v4c 20/10：+2.72%、组合中位 +56.7%、回撤最低（23.4%~24.6%），是最接近 v1 的方案
   - v4 15/8：胜率 39.9%，但回撤摆到 50.0%，风险大
   - v4b 10/5：胜率最高 44.1%，但单笔掉到 +1.96%、组合中位仅 +4.6%——涨一点就锁，把趋势腰斩
   - v2（无超时）组合中位 +6.1%，远差于 v2b（有超时）+18.3%

4. **规则不是越多越好**
   v5 堆叠全部规则，单笔 +0.97%、组合区间全为负，全场最差。最早触发的那条永远
   说了算，持仓只剩 15.5 天，任何趋势都吃不到。

## 为什么 v1b 而不是 v1 / v4c

v1 单笔略高（+2.70% vs +2.61%），但 v1b 组合中位更好（**+68.5%** vs +43.5%）且
上限更高（+75.8%）。年线这条触发不多，在大级别转熊时提供保护。
v4c 单笔最高（+2.72%）且回撤最低，是**次选方案**——若更看重回撤控制可选它。

## 实施要点（易错处）

1. **顶背离必须只在"完成当根"触发**：若标志位持续为真，入场前形成的旧背离会误杀
   新仓位。实现为单根触发（正柱区间结束那根）。
2. **顶背离判定与生产 `_top_divergence_risk` 逐根等价**：`min_segment_bars=1` 时
   58 个触发点全一致（已写入测试）。
3. **超时是"计划性退出"**：引擎在 `index == timeout_idx` 时按**当根开盘价**成交，
   且先于当根止损判定；研究实现最初写成"次日开盘"，导致 13/69 笔差异，已对齐。
4. **v1b 不设固定止盈**：若保留 `take_profit_pct`，+30% 会截断赢家，静默改变策略。
5. **作用范围隔离**：`mode` 会作用于所有走 `simulate_single_trade` 的策略，
   必须用 `apply_to_signal_types` 限定。

## 顶背离：实盘与回测曾经是两套定义（2026-10-05 修复）

做"有持仓就提醒卖出"时才发现：**实盘提示的顶背离卖点，不是回测里验证过的那个卖点。**

| | 实现 | 判定 |
|---|---|---|
| 回测（`_build_trend_exit_flags`） | 正柱周期切换，比较周期内**最高价** | 最高价**创新高** 且面积收缩 |
| 实盘（`registry.evaluate_exits`） | `bottom_divergence_at(-hist, -high, ...)` 取负复用底背离 | 「最高价**未创新高**」且面积收缩 |

实盘那行想"取负镜像复用底背离函数"，但取负之后「创更高价」变成
`price_change_pct > 0`，而底背离的判定是 `price_change_pct < 0`——**方向被反转**。
逐日比较 3 只股票 360 个交易日，两条路径**从来没有在同一天同时触发过**
（都不触发 1330 天、仅回测 254 天、仅实盘 16 天，合计 16.9% 的日子不一致）。

根因是两个函数连**周期边界**都不一样：

- 回测按**柱体正负翻转**切分；
- 底背离函数按**零轴 DIF/DEA 金叉死叉**切分，且 `min_segment_bars` 默认 5，
  比回测的隐含阈值（≥1）严格。

**修复**：顶背离只有一份实现（`strategy.macd_divergence.top_divergence_flags`），
回测与实盘都调用它；顺带修掉另一处不一致——实盘算年线时
`rolling(250)` 没带 `min_periods`，历史不足 250 根时会用不足 250 根算出一条"年线"
（回测是 `min_periods=period`，不足则视为未知）。

**影响面**：

- **回测结论不变**：重跑 `eng_fixed` / `eng_v1b` 的退出原因分布**逐字节一致**
  （止损 240 / 顶背离 138 / 超时 134 / 破年线 47），
  `div_exit_engine.json` 无需重新生成。
- **实盘此前偏保守**：「最高价未创新高」比「创新高」更容易成立，
  所以过去网页上那个「退出条件触发」徽章**报得偏多**；
  修复后实盘与回测在同一根 K 线触发，一致性测试：
  360 个交易日 0 处不一致。
- 本文件第 2 条（与 `_top_divergence_risk` 58 个触发点一致）说的仍是**退出层内部**
  的自洽性；生产 `registry` 当时用的是另一套判定，两者都自洽但互不相同。
  现已统一，回归测试见 `tests/test_top_divergence_definition.py`。

## 已知局限

- **幸存者偏差**：缓存是当前仍存在的 5007 只，已退市样本缺失，绝对收益偏乐观。
- **单一时间窗**：2023-05 起仅一轮周期，未做样本外切分；559 笔信号里 350 笔集中在 2025 年。
- **无市场闸门 / 股票池过滤**：两条臂都不加，差异只来自卖出规则。
- **4 仓位约束**：组合数字被容量支配，故一律报区间；单笔均值/PF 是更可信的比较口径。
