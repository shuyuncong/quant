# 缠论信号监控 Web 控制台 - 需求文档

## 背景与目标

现有 CLI 系统（quant-python/signal_system）已具备分析、扫描、监控与推送能力。本需求新增一个 Web 控制台，让用户不依赖命令行即可：

- 查看分析/扫描/监控结果；
- 配置按哪些策略分析、推送方式、LLM 模型（地址/key）、定时分析时机；
- 维护股票池，支持文本与图片两种方式导入。

## 功能需求

### FR-1 结果查看
- 展示最近 analyze / scan / monitor 结果，来源为 output/*.json 与任务运行记录。
- 支持按类型与时间筛选，查看单条结果详情（周期指标、缠论结构、评分、信号事件）。
- 配置模型后，结果详情展示 AI 解读（作为补充字段，不改变原始分析结果）。

### FR-2 策略配置
- 页面可编辑：缠论参数（min_bi_bars / divergence_ratio / fresh_signal_bars）、MACD 参数（fast/slow/signal/zero_axis_tolerance）、监控周期列表、评分阈值、monitor.watchlist、scan 模式。
- 保存后写入 Web 设置库；运行时配置优先级：环境变量 > Web 设置 > config.yaml。

### FR-3 推送配置
- 配置微信 webhook / 通用 webhook / 邮件三通道的开关、地址、密钥、收件人。
- 提供“发送测试通知”按钮，复用现有 SignalNotifier 验证通道。

### FR-4 模型（LLM AI 分析）配置
- 支持 1~N 个 OpenAI 兼容接口配置：名称、base_url、model、api_key（可选绑定环境变量名）。
- 可启用/停用、测试连通性。
- AI 解读作为信号/个股报告的补充字段；未配置可用模型时系统照常运行。

### FR-5 定时分析配置
- 页面配置：每日扫描时间、分钟监控间隔、是否仅交易日执行、总开关。
- Web 进程内调度器按配置触发任务；页面展示下次运行与最近运行状态。

### FR-6 股票池管理
- 股票池 CRUD（symbol、名称、来源）。
- 文本导入：粘贴代码列表（支持逗号/空格/换行分隔，可带名称行），先解析预览再确认入库。
- 图片导入：上传截图，调用配置的视觉模型识别候选股票，页面确认后再入库；未配置模型时明确提示改用文本导入。

### FR-7 手动触发
- 页面按钮触发 analyze（自选股或指定股票）、scan、monitor once、测试通知；运行状态与结果回显。

## 非功能需求

- NFR-1 配置优先级：环境变量 > Web 数据库 > config.yaml（load_config 仍负责默认值与 YAML 环境变量展开）。
- NFR-2 密钥可存 Web 数据库，也可由环境变量提供；环境变量存在时优先。
- NFR-3 本地运行（默认 127.0.0.1），v1 不做登录；上线前必须加访问密码，预留鉴权扩展点。
- NFR-4 不改变现有 CLI 行为；CLI 与 Web 可并行使用。
- NFR-5 结果与任务历史持久化（SQLite + output JSON 文件）。

## 验收标准（概要）

1. 浏览器打开控制台即可看到结果列表与详情。
2. 修改策略/推送/模型/定时配置并保存后，下一次分析生效。
3. 文本与图片导入股票池均可完成，图片导入必须经过页面确认。
4. 定时任务按配置触发，页面可见最近/下次运行状态。
