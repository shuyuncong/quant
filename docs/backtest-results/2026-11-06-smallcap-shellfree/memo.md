# 小市值优化 v2：shell-free（剔除最小 30%）+ 文献复核

## 结论

**把“壳价值”这一段剔掉后，策略从“亏”变成“微赚”，但仍然远不如 ETF。**

| 指标 | v2 shell-free | v1 全小市值 | ETF 基准 |
|---|---:|---:|---:|
| CAGR | **4.50%** | 1.05% | 9.87% |
| Sharpe | **0.386** | 0.167 | 1.200 |
| 最大回撤 | **−24.74%** | −30.44% | −10.19% |
| 交易胜率 | 46.02% | 45.35% | 52.94% |
| 盈亏比 | 1.376 | 1.305 | 1.892 |
| 年均换手 | 11.29x | 8.44x | — |
| 平均仓位 | 56.8% | 44.1% | — |
| 平均持仓 | 47.96 | 43.89 | — |

分段：

| 区间 | CAGR | Sharpe | 最大回撤 |
|---|---:|---:|---:|
| 2020–2024 训练 | 4.99% | 0.399 | −24.74% |
| 2025–2026 holdout | 3.17% | 0.290 | −18.74% |

**shell-free 改善了收益和回撤，但没有把 Sharpe 做到 0.8 以上；仍不可投。**

## 文献依据

### 1. A 股最小的 30% 是“壳价值”污染区

Liu, Stambaugh, Yuan (2019, JFE) *Size and Value in China*：

- A 股最小的 30% 市值公司，约 **30% 的市值**反映“反向并购壳价值”；
- 83% 的反向并购壳来自最小 30%；
- 这些股票的收益与基本面（盈利惊喜）关系更弱，与 IPO 政策/壳价值关系更强；
- 构造中国三因子时应**剔除最小 30%**；否则 size/value 因子被污染。

这直接解释了：
- 我们原来选“最小 50 只”正好在壳价值区；
- 2024 年退市/IPO 改革后壳价值压缩，策略出现 −45% 回撤；
- v2 剔除最小 30% 后，回撤从 −30% 降到 −25%，收益从 1% 提到 4.5%。

来源：NBER w24458 / JFE 2019。

### 2. 中国最强的价值因子是 EP，不是 BM

同一篇论文：
- EP（盈利/价格）在中国显著优于 BM；
- 规模 + EP 的三因子（CH-3）能解释大部分中国异象；
- 盈利、低波异象基本被 size/value 解释；
- **中国没有动量，过去 1/3/6/12 个月都倾向反转**；
- 反转和异常换手需要额外的 turnover 因子。

一项 2000–2023 的 EP+ME 研究给出的现实收益是：

> **4.17% 年化 / Sharpe 0.17 / 最大回撤 38.35%**

这和我们 shell-free v2 的 **4.50% / 0.386 / −24.74%** 同一量级。

来源：He (2025), *Mitigating Shell Value Contamination in China’s A-Share Market*；Atlantis Press。

### 3. 波动率目标是风控，不是 alpha

Man Group / Harvey et al. 的波动率目标研究：
- 对股票/信用等风险资产，vol targeting 通常能提高 Sharpe、降低尾部；
- 但它是**风险管理**，不是收益引擎。

我们的 v2 用 10% vol target + 回撤降仓：
- 回撤从 −30% 降到 −25%；
- 收益从 1% 提到 4.5%；
- 但平均仓位只有 56.8%，收益被风险预算限制。

### 4. 2024 微盘股崩盘是“拥挤 + 壳价值 + 流动性”的合成

2024 年初小微盘/量化指增出现历史级回撤，媒体和券商归因于：
- 小市值暴露过高；
- 雪球/DMA/基差/流动性冲击；
- 壳价值/退市政策变化。

这和我们的 PIT 结果一致：**小市值不是稳定 alpha，是政策和流动性 beta。**

## v2 设置

- 股票池：PIT 全 A + 237 只退市股；
- **剔除最小 30% 市值**（shell-free），选排名 30%–50% 的 50 只；
- 价格 ≥2、上市 ≥250 天、ADV20 ≥5000 万；
- 行业 ≤25%；
- 月度，no-trade band 5%；
- 10bp 滑点、1% ADV；
- 10% vol target；回撤 −15% 半仓，−25% 保留 25% 风险仓；
- 无个股止损。

## 为什么仍然不够

1. **收益只有 4.5%，跑不过 ETF 9.87%。**
2. **回撤 −24.7%，仍是 ETF −10% 的 2.4 倍。**
3. **Sharpe 0.386，距 0.8 的门槛很远。**
4. **换手 11.3x，成本仍然敏感。**
5. **没有 EP/value 过滤。** 文献里 EP 是中国最强价值因子；但全 A PIT 财务数据没有，v2 无法加。

## 下一步（有证据支撑）

1. **不要再调 size 参数**；shell-free 已经接近文献里 size/value 的现实水平。
2. 如果拿到全 A PIT 财务，测试 **EP + ME**：
   - 预期不是 30%，而是文献的 4%–10% 量级；
   - 先看能否把 Sharpe 做到 0.8、回撤 <25%，否则仍 reject。
3. 若要加反转/异常换手，必须按 CH-4 的方式做 **月频/低换手**；日频反转会被成本吃掉。
4. **不要用 MACD/动量**：中国没有动量，过去收益整体反转。

## 决策

- **不投产。**
- 不买数据救 size；如果买数据，是为了验证 EP+ME，而不是继续调小市值。
- 这条线目前的最好版本是 **4.5% / 0.386 / −24.7%**，仍不如 ETF。
