# 首板低开：15m 小级别进场验证（2026-11-16）

## 结论

**小级别确认没有改善，反而破坏了首板低开的边际。** 等待 15m 收复开盘价/突破第一根高点，会把入场价推高 2%–5%，把原本 52% 胜率、1.46 盈亏比的边际吃光。

## 预注册口径

- 信号：完全复用首板低开的 277 个信号（2020-01-02 → 2026-10-30），不新增选股条件。
- B0：T 日开盘价直接买（基线）。
- B1：T 日 15m 收盘首次 > T 日开盘价，下一根 15m 开盘买。
- B2：15m 收盘首次 > 第一根 15m（09:30–09:45）最高价，下一根开盘买。
- B3：B2 + 确认根成交量 ≥ 1.5×第一根量。
- 确认截止 11:15；未确认当天放弃。
- 出场统一 T+1 日 14:45 的 15m 收盘，隔离进场变量；另列源码式 11:30 有浮盈先卖。
- 成本：佣金 3bp/边、印花税 10bp、滑点 10bp/边。
- 数据：BaoStock 15m 前复权，277 个信号全部有数据（2 天价格偏差 >0.5% 做了缩放）。

## 解释

首板低开的 alpha 来自**开盘那一刻的低开定价**，不是后面的 15m 结构。等 15m 确认时，价格已经回到开盘价上方 2%–5%，等于把“低开折价”让给了市场。用缠论的话说：开盘低点本身就是小级别的转折点，15m 确认是**离开转折点之后**才上车，盈亏比和胜率同时下降。
