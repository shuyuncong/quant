# PIT 全 A 中大盘质量价值 + MA200 风险开关（2026-11-10）

状态：**预注册研究完成，结论 reject。不改变生产配置、不接券商、不下单。**

## 1. 预注册设计

| 项 | 取值 |
|---|---|
| 股票池 | PIT 全 A + 有本地行情的退市股（5,059 个价格代码，244 个退市代码） |
| 中大盘 | PIT 流通市值排名百分位 70%–100%，即剔除最小 70% |
| 过滤 | 价格 ≥2、上市/历史 ≥250 日、ADV20 ≥5,000 万元 |
| 财务 | 最新年度报告，`available_date <= 信号日`；归母净利润 >0、营业收入 >0、ROE >0；报告年龄 ≤500 天 |
| 质量 | `0.5 * ROE 截面百分位 + 0.5 * 净利率截面百分位` |
| 价值 | `EP = 归母净利润 / PIT 流通市值` |
| 综合分 | `0.5 * 质量 + 0.5 * 价值` |
| 选股 | 综合分前 50，行业 ≤25% |
| 风险开关 | PIT 流通市值加权全 A 指数收盘 > 200 日均线；否则下一开盘清仓持币 |
| 执行 | 月度、下一交易日开盘、5% no-trade band、整手、佣金/印花税 |
| 成本 | 10bp 单边基础，20bp 压力 |
| 风险叠加 | 无波动率目标、无回撤降仓；MA200 是唯一开关 |
| 设计段 | 2020-01-02 → 2024-12-31 |
| 时间 holdout | 2025-01-01 → 2026-10-30（此前已观察，不是严格 OOS） |
| 验收 | Sharpe ≥1.0、最大回撤 ≤20%、20bp 年化 ≥8% |

所有参数在首次运行前固定；没有根据结果调整质量权重、MA200 窗口、持仓数或行业 cap。

## 3. 选中特征

| 时点 | 池内候选 | 有完整财务 | 选中流通市值中位数 | 选中 EP 中位数 | 选中 ROE 中位数 | 选中净利率中位数 |
|---|---:|---:|---:|---:|---:|---:|
| 2019-12-31 | 857 | 797 | 198.3 亿 | 18.74% | 26.95% | 26.46% |
| 2026-09-30 | 1,405 | 1,250 | 365.1 亿 | 12.84% | 18.18% | 37.46% |

这不是微盘暴露：选中的是实打实的中大盘。问题在于高 EP + 高 ROE/高净利率在这段样本里更像价值陷阱，而不是质量溢价。

## 4. 结论

1. **质量价值信号本身没有做出 edge。** 无 MA200 版本年化 1.18%、Sharpe 0.157；加入质量没有超过此前的壳价值基线，更没有接近 ETF。
2. **MA200 开关在这段样本里是负贡献。** 它把 2022 年亏损从 -14.03% 压到 -4.59%，但 2023、2024 的修复年被空仓错过；全期年化从 1.18% 降到 -0.89%，最大回撤只从 -29.56% 改善到 -28.79%。
3. **市值前 50 对照更差。** 大市值本身不提供收益；MA200 下也只有 0.29% 年化、0.086 Sharpe。
4. **2025–26 holdout 的正收益不足以救结论。** 主变体 holdout 7.44%/0.794，但 2020–24 设计段为负；且 holdout 已被前期研究查看，不是干净样本外。
5. **验收三项全部失败。** Sharpe -0.025、回撤 -28.79%、20bp 年化为负。

**判决：reject。不进入纸面，不进入生产，不继续调质量权重、净利率、MA200 窗口或持仓数。**

## 5. 限制

- 全 A 年度 PIT 面板没有资产负债率字段；质量分只有 ROE 与净利率，不是完整的低杠杆质量定义。
- 只用了年度报告，没有用 TTM；TTM 质量价值是另一个假设，不能把本轮结果外推。
- 没有历史 CSI 300/全 A 指数，MA200 用的是本地 PIT 流通市值加权全 A 代理指数。
- 没有历史 ST 名单；价格/ADV/历史长度只是代理。
- 只有 244 个退市代码有本地行情；其余退市股缺失。
- 2025–2026 已被前期研究查看，只能算时间 holdout，不是严格 OOS。
