# 小市值 PIT 基线：成本压力与稳健性矩阵（2020–2026）

## 结论

**没有一条在合理风险下站得住。**

- 基准（PIT 全 A + 237 只退市，严格 50，5bp）：**−2.03% CAGR / Sharpe −0.014 / 最大回撤 −45.45%**
- 滑点 10bp：**−4.79% / −0.173 / −50.04%**
- 滑点 20bp：**−9.98% / −0.490 / −58.80%**
- 换排名带 501–1500 / 1000–2000：**−1.55% / −1.62%**，仍然负
- 去掉行业 cap：**+4.40% / 0.303 / −45.34%**，是唯一正收益，但回撤仍 45%
- 池 150：**+5.33% / 0.342 / −47.34%**
- 动态 3–6 只（池 50）：**−7.77% / −0.086 / −68.09%**

**成本是第一杀手，行业 cap 是第二变量；两者都救不了风险。**

## 解读

1. **10bp 滑点就吃掉约 2.8pp CAGR，20bp 吃掉约 8pp。**  
   年均换手 53x，成本敏感性极高；微盘 5bp 本来就偏乐观。

2. **换排名带没有改善。**  
   501–1500、1000–2000 都在 −1.5% 左右，说明不是“选错 800–1800”这一段，而是整个小市值池在扣成本后没有正期望。

3. **去掉行业 cap 变成 +4.4%，但回撤仍 −45%。**  
   这更像行业集中暴露，不是稳定 alpha；不要因为一个变体转正就认为找到答案。

4. **池 150 的 +5.33% 也不可投。**  
   回撤 −47%，Sharpe 0.34；同样是小市值 beta + 幸存者偏差残余（仍有 130 只退市股缺行情）。

5. **动态 3–6 只（池 50）最差：−7.77% / −68.09%。**  
   集中持仓放大尾部；之前池 150 的动态版本好看，是池子不同，不是止损/动态持仓的功劳。

## 决策

- **不投产。**
- 不再为这个策略买历史 PIT 数据；免费 PIT 全 A 已经给出负期望。
- 如果还要研究，只做两件事：
  1. 找**新的、有经济逻辑的信号**，而不是继续调小市值参数；
  2. 若坚持小市值，先解决退市股剩余 130 只、行业分类和容量，再谈。
