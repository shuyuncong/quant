# 首板缩量回调 V1–V5：按你的规则逐层验证（2026-11-16）

## 结论

**只有 V1（回调 10%–25%，但不破首板日最低价）把事件期望从负转正。**  
V1：476 笔，净均值 **+0.48%/笔**，胜率 47.5%，盈亏比 1.30，PF 1.17，t=1.36；设计段 +0.50%、留出段 +0.45%，方向一致。但 t 值不到 2，95% 区间仍跨 0，属于“有改善、未证明”。

再往上叠加「50% 缩量 + 地量横住 2 天 + 量能转折 + MA20 + 站上 MA20 + 冰点」后，样本从 476 → 38 → 8 → 4 → 0，**无法验证**。

## 逐层定义（预注册，不调参）

| 变体 | 规则 |
|---|---|
| V0 | 原基线：回调 ≤8%，量 ≤60% 首板量且 ≤20 日均额，1–3 日内首次满足，次日开盘买 |
| V1 | 回调 10%–25%，不破首板日最低价；量 ≤60% 首板量且 ≤20 日均额；1–10 日内首次满足 |
| V2 | V1 + 量 ≤50% 首板量 + 至少 2 个连续地量日 + 之后首次放量（≥1.5×前一日）收阳 |
| V3 | V2 + 转折日收盘距 MA20 ≤3%，MA20 五日斜率 ≥0 |
| V4 | V3 + 转折日收盘 > MA20（放量站上 MA20） |
| V5 | V4 + 首板日「冰点/启动期」：最高连板 ≤2 且涨停家数 ≤前 20 日中位数 |

所有变体共用：首板放量 ≥2×20 日均额、价格 ≥2、ADV20 ≥2000 万、-5% 止损/+10% 止盈/最多 5 日、成本 3bp/10bp/10bp。

## 关键解释

**1. 你强调的「回调 10%–25%」确实可能是对的。**  
原基线只允许 ≤8%，把很多正常洗盘排除在外；V1 放宽到 10%–25%，同时用「不破首板日最低价」兜底，事件均值从 -0.82% 变成 +0.48%。这说明“回调深度”本身不是问题，“破启动低点”才是问题。

**2. 但「50% 缩量 + 地量横住 + MA20 + 站上 MA20」叠加后样本崩溃。**  
V2 只剩 38 笔，V3 8 笔，V4 4 笔。不是规则错，而是 A 股日线里同时满足这些条件的首板样本极少；用 4 笔交易判断“黄金买点”没有统计意义。

**3. 冰点/启动期过滤在这套定义下没有可用样本。**  
全市场冰点日有 350 天，但 V4+冰点交集为 0；V1+冰点也只有 2 笔。说明“冰点”与“深度回调+MA20 确认”在时间上几乎不重叠，或者冰点定义过严。这个方向需要重新定义情绪周期，不能直接套。

**4. 不要把 V0 的负期望和 V1 的正期望混在一起。**  
V0 是“浅回调、早买”；V1 是“深回调、不破启动低点、仍然次日买”。两者结构不同。V1 是这次唯一值得继续研究的版本。

## 口径与限制

- 首板定义：20 日内首次涨停；放量 ≥2×20 日均额。
- 无历史 ST 名单；ST 5% 涨停未识别。
- qfq 日线；2024-12-31 拼接，跨拼接交易剔除。
- 无盘中分时；V2–V4 的“量能转折/站上 MA20”用日线收盘判断。
- 组合为 5%/笔、20 槽；V1 的绝对收益被仓位限制，不能直接与满仓首板低开比较。
- 2026 为 YTD；V3/V4 样本几乎全在 2025–2026。
