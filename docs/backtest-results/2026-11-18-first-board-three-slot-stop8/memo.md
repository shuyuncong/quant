# 首板低开 vs 首板缩量回调 V1：最多 3 只 / 单票≤40% / 浮亏 8% 止损（2026-11-18）

状态：研究回测，不接生产、不自动交易。

> 2026-11-27 修正：涨停判定原先恒真（`high >= close - 0.005`），摸到涨停、收盘没封住的板也被算成首板。这里的数字是旧口径；同口径重跑（低开 257 → 242 笔、总收益 +175.0% → +190.9%、回撤 −24.3% → −19.0%，仍优于回调 V1）见 [`../2026-11-27-first-board-low-open-sealed/README.md`](../2026-11-27-first-board-low-open-sealed/README.md)。

## 结论

两条策略各自一个 100 万账户，账户规则完全相同，2020-01-02 → 2026-10-30（2026 为 YTD）：

| | 首板低开 | 首板缩量回调 V1 |
|---|---:|---:|
| 总收益 | **+175.0%** | **+94.6%** |
| 年化 | +16.7% | +10.7% |
| Sharpe | 0.90 | 0.53 |
| 最大回撤 | -24.3% | -25.7% |
| 胜率 | 50.6% | 48.3% |
| 利润因子 | 1.45 | 1.14 |
| 成交笔数 | 257 | 410 |
| 可买信号 / 因仓位已满放弃 | 277 / 20 | 493 / 83 |
| 单笔净收益均值 | +1.18% | +0.57% |
| 平均持有 | 1.1 日 | 3.9 日 |
| 平均仓位 | 6.7% | 35.1% |
| 100 万 → | 275.0 万 | 194.6 万 |

1. **低开仍然更好**：收益高约 80pp，Sharpe 0.90 对 0.53，回撤相近；而且低开平均只用了 6.7% 的仓位，V1 用了 35.1%。
2. **两条曲线都靠少数几笔交易撑着**：去掉贡献最大的 5 笔，低开剩 +52.9%，V1 剩 +10.4%；去掉 10 笔，低开 +11.4%，V1 变成 -22.5%。
3. **8% 止损对低开是负贡献，对 V1 作用不确定**：低开不加止损是 +214.0%（Sharpe 1.00），随机换 200 次取舍顺序，止损每一次都降低总收益；V1 多数情况下略有帮助，但区间跨 0。两边的回撤都没有稳定改善。
4. **止损价不是成交价**：跳空低开和跌停时卖得更低，最差单笔低开 -13.3%、V1 -19.3%。

## 账户规则

- 初始 100 万；两条策略各自独立账户，互不占用仓位。
- 最多同时持有 3 只。当日可买候选多于空仓位时，多出来的直接放弃，之后不补买。
- 单票买入金额 = min(40% × 买入时总资产, 可用现金 ÷ 当日买入只数)；不加杠杆，持有期不再平衡。所以依次买入时前两只各 40%，第三只只能用剩下约 20% 的现金；同日买 3 只时各约 1/3。
- 浮亏 8% 止损：买入次日起（T+1），盘中最低价触及 成本 × 0.92 即卖出，成交价取 min(开盘价, 止损价)；全天封死跌停卖不掉，顺延到下一个不跌停的开盘。成本为含滑点的买入价。
  - 如果按收盘价判断，这条规则几乎不起作用：V1 自带的收盘 -5% 止损会先触发，低开本来就在次日收盘卖。所以按盘中触及执行。
- 100 股整手；佣金 3bp/边（最低 5 元）、卖出印花税 10bp、滑点 10bp/边。

选股和策略自带的卖出规则不变：

- **首板低开**：昨日首板、今日低开 3%–4%、60 日相对位置 ≤50%、上市 ≥250 日；开盘买，次日收盘卖；收盘涨停继续持有，收盘跌停卖不掉。
- **首板缩量回调 V1**（冻结规则）：首板放量后 1–10 日内回调 10%–25%、不破首板日最低价、成交额 ≤60% 首板日；确认后次日开盘买；收盘 -5% 止损 / +10% 止盈 / 第 5 个收盘到期，均次日开盘卖。

有两处和原研究不同：

- 首板低开源码只在空仓时买。这里改成有空仓位就买，否则“最多 3 只”没有意义。源码口径（空仓才买）作为对照：+182.5% / Sharpe 0.97 / 回撤 -28.4%，213 笔。
- V1 原事件模型会把“跌停顺延超过 5 日”和“持有期跨 2024-12-31 复权拼接点”的交易整笔剔除。账户回放不能事后剔除：卖不掉就一直持有到能卖；2024-12-31 当天不开新仓、收盘强平仍持有的仓位（主口径下跳过 1 个信号，没有被强平的仓位）。

## 结果有多稳

### 1. 放弃哪几只是任意的

规则只说“多于三个的放弃”，没说放弃谁。主口径：V1 按首板放量倍数从大到小取（原研究的同日排序）；低开源码没有排序，按代码升序取。把同日取舍顺序随机打乱重跑 200 次（种子固定）：

| 5% 分位 / 中位 / 95% 分位 | 首板低开 | 首板缩量回调 V1 |
|---|---:|---:|
| 总收益 | +165.7% / +185.1% / +202.0% | +53.9% / +81.9% / +115.0% |
| Sharpe | 0.88 / 0.94 / 0.98 | 0.39 / 0.49 / 0.59 |
| 最大回撤 | -24.3% / -21.2% / -20.8% | -28.7% / -25.7% / -25.7% |

低开只放弃 20 个信号，区间窄。V1 放弃 83 个，仅仅换一下取舍顺序，总收益就能差一倍。V1 主口径的 +94.6% 落在这个区间内，不能当成“按放量倍数排序有效”的证据：反向排序 +72.4%，按代码升序 +100.4%，按代码降序 +67.3%。

### 2. 8% 止损的作用

| | 首板低开 | 首板缩量回调 V1 |
|---|---:|---:|
| 有止损（主口径）总收益 / Sharpe / 回撤 | +175.0% / 0.90 / -24.3% | +94.6% / 0.53 / -25.7% |
| 不加止损 | +214.0% / 1.00 / -25.0% | +77.3% / 0.47 / -30.4% |
| 8% 止损成交笔数 | 30 | 55 |
| 止损单平均净收益 | -8.9% | -8.6% |
| 最差单笔净收益 | -13.3% | -19.3% |
| 随机顺序下止损对总收益的影响（5% / 中位 / 95%） | -47.8 / -34.1 / -27.2 pp | -2.4 / +9.5 / +22.0 pp |
| 止损提高总收益的顺序占比 | 0% | 88.5% |
| 随机顺序下止损对回撤的影响（中位） | +0.1 pp | +0.4 pp |

- **低开**：止损是负贡献。低开本来次日收盘就卖，止损只是把盘中跌破 -8% 的票提前在更低的价位卖掉，其中有的收盘前会收回来；回撤没有因此变小。
- **V1**：自带收盘 -5% 止损，盘中 8% 止损多拦了 55 笔。多数顺序下账户收益略高，但 5% 分位为负；主口径下回撤改善 4.6pp，随机顺序下中位只有 0.4pp，不能当成稳定效果。
- **止损价不保证成交**：按止损价成交时净亏约 8.2%。跳空低开或跌停时成交更低，所以止损单平均亏 8.6%–8.9%，最差单笔亏到 13%–19%。

### 3. 收益集中在少数几笔

单票 40% 意味着一笔 +40% 的交易就让账户涨 16%。贡献最大的 5 笔占全部交易贡献之和的比例：低开 56%，V1 66%。去掉贡献最大的 N 笔信号后重跑账户：

| 去掉最赚的 | 首板低开 | 首板缩量回调 V1 |
|---|---:|---:|
| 0 笔（主口径） | +175.0% | +94.6% |
| 3 笔 | +80.3% | +37.1% |
| 5 笔 | +52.9% | +10.4% |
| 10 笔 | +11.4% | -22.5% |

- 低开：因收盘涨停继续持有而拿了 3 个交易日以上的 7 笔交易，贡献了全部交易贡献之和的 56%。策略的大部分收益来自“买到之后连板”，其余两百多笔合起来只是小赚。
- V1：贡献最大的 10 笔全部是 +10% 止盈触发后次日开盘卖出的单子，其中 9 笔是创业板/科创板（20% 涨跌幅）。

所以这两个数字不是“每年稳定赚这么多”，而是“七年里有没有碰上那几笔”。

## 和之前结果的关系

- 首板低开·单票≤1/3（源码口径：空仓才买、不限只数、无硬止损）2020–2026 是 +174.9% / Sharpe 1.08 / 回撤 -23.3%，219 笔。本次 +175.0% 与它几乎相同是巧合：本次 257 笔，逐年收益不同（2020 年 +3.7% 对 +10.7%）。3 只 / 40% 多买了一些信号，8% 止损又把收益压了回去。
- V1 在 5% × 20 槽下是 +10.9% / Sharpe 0.42 / 回撤 -5.2%。集中到 3 只 × 40% 后，收益放大约 9 倍、回撤放大约 5 倍，Sharpe 只从 0.42 到 0.53。
- 统一 5% 仓位时低开 Sharpe 0.98、V1 0.41；集中持仓后低开 0.90、V1 0.53。两者的先后顺序没有变。

## 口径与偏差

- 日线回测。盘中 8% 止损假设价格触及就能按止损价成交；真实盘中有滑点，急跌时更差。
- 首板低开源码在次日 11:28 / 14:50 卖出，这里用收盘价近似。
- 无历史 ST 名单，ST 的 5% 涨跌停识别不了。V1 有 1 笔（002121，2020-04-28 买入）在 5% 一字跌停的 K 线上按开盘价卖出，实际卖不掉，亏损被低估。
- V1 的“缩量”条件会把一字跌停日当成缩量回调。最差单笔 603110（2023-04-11 买入）就是在连续一字跌停中买入，两天卖不掉，亏 19.3%。这是冻结的 V1 规则本身的问题，本次没有改。
- 退市股用东财不复权日线，低开有 25 笔、V1 有 12 笔成交在这类股票上；持有期碰到除权日时涨跌幅会失真。
- 两条策略用的行情面板不同：低开用 2018–2026 复权面板，V1 用 BaoStock + 本地 qfq 拼接。
- 账户回放核对过：用原参数能逐笔复现已发布的单票≤1/3 基线（2019 年起 257 笔、期末 369.4 万，完全一致）；V1 不限仓位、不加硬止损时，493 笔里 491 笔的出场日和出场原因与冻结事件模型一致，另 2 笔是样本末尾未平仓。
