# 生产选出来的股票，按当时的规则回放（2026-11-26）

状态：研究回放。只读生产的扫描报告和日线缓存，不下单，不改生产。行情到 2026-11-25 收盘。

## 结论

**三个扫描策略选出来的票，按各自的卖出规则回放，平均每只都是亏的。同一段时间全市场也在大跌：全 A 等权 -19.9%，沪深300ETF -15.1%（2026-08-24 → 11-25）。只有首板低开纸面账本是正的，但它只有 8 笔。**

"同期"指每只票自己的持有区间（买入日开盘 → 卖出日收盘，还拿着的算到 11-25），再对所有票取平均。

1. **大多数票是止损出局的。** 中位数 -8.19% 就是 8% 止损加买卖费用。零轴金叉 539 笔里 291 笔止损（54%），年线趋势 139 笔里 103 笔（74%）。其中 9 笔是跌停卖不出、第二天开盘才卖掉的，亏 9%–23%。
2. **赚钱的票少，而且多数还没卖。** 已卖出的均值是 -6.49%（零轴金叉）、-7.81%（年线趋势）、-7.37%（底背离）；还拿着的按 11-25 收盘价算是 +1.76%、+0.36%、-1.25%，没有扣卖出费用，也还会变。止盈（+30%）一共 13 笔。
3. **零轴金叉比同期全 A 等权少亏 5.55 个百分点，年线趋势和全 A 等权差不多。** 这个差不能读成"选股有效"，原因见下面的边界：差里面包含了止损规则的作用，票集中在少数几天，225 笔还没有结果。
4. **闸门没有把好票和坏票分开。** 零轴金叉里，生产认定可入场的 140 只均值 -2.58%，被仓位闸门降为仅观察的 313 只 -3.70%，被大盘闸门拦下的 37 只反而是 +0.84%。样本小，买入日分别只有 14、23、7 天，不下结论。

## 口径

- **选股来源**：生产每日扫描落盘的报告 `/opt/docker/quant/output/scan*.json`。同一只票同一个信号日只算一次，第一次出现在报告里的时间记为发布时间。零轴金叉 2026-08-21 起，年线趋势 09-14 起，底背离 10-08 起。
- **买入**：发布之后的第一个开盘价。9:25 之后才扫出来的票等下一个交易日。全市场扫描分批跑，零轴金叉有 46% 的票是信号日之后才第一次出现在报告里的。
- **卖出**：直接调用 Web 本地回测的 `research_backtest.replay`，规则和生产的卖出提醒同源。零轴金叉、年线趋势：-8% 止损、+30% 止盈、最多持有 40 根日线。底背离：-8% 止损、顶背离或跌破年线卖出。日线内同时碰到止损和止盈时算止损。
- **费用**：佣金 0.03%（最低 5 元）、卖出印花税 0.05%、滑点 0.05%，按 100 股取整。
- **配置**：本地 `config/config.yaml`，和生产检出的版本逐字节一致。
- **基准**：沪深300ETF（510300）和全 A 等权。全 A 等权是沪深 A 股里买入日开盘、卖出日收盘两头都有价格的股票的平均收益，不含费用。选股范围是全 A，所以它才是"同一段时间随便买"的对照。
- **行情**：生产日线缓存（前复权），截到股票行情已经刷完的最后一个交易日。
- **没成交的 3 只**：2 只开盘涨停买不进，1 只 11-25 晚上才发布、还没有开盘。

## 边界

- **只有一段下跌行情。** 三个月里全 A 等权跌了近 20%。这些规则在上涨或震荡行情里的表现，这份结果说明不了。
- **"比全 A 等权少亏"不等于选股有效。** 票被止损后就不再跟着市场下跌，对照组没有止损；这个差是"选股 + 止损"合在一起的结果。没有做显著性检验：539 笔集中在 28 个买入日，持有区间互相重叠，不是 539 个独立样本。
- **同一只票会被算多次。** 零轴金叉的 541 条入选只对应 239 只股票，同一只票隔几天再出信号会各算一笔，两笔的持有区间可能重叠。
- **还拿着的 263 笔没有结果。** 按 11-25 收盘价盯市，没有扣卖出费用。
- **止损按止损价成交。** 日线看不到盘中路径，开盘没有跳空时假定正好卖在止损价。
- **底背离只有 11 只**，不下结论。
- **不含实际持仓。** 生产数据库里的真实持仓和买卖记录不在这份回放里。
- 生产动作：none。
