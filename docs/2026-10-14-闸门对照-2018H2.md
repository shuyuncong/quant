# 闸门对照回测 · 2018H2 —— 结论：**该窗口无法回答**

> **一句话**：2018H2 是本会话"补齐 2018–2022 数据"后理论上最想补的一格（熊市窗口），
> 但实测**两侧同时为空** —— 闸门 **0/124 天开放**、研究样本 **0/5008 只**。
> 这**不是**"闸门把信号全掐掉"那种可解读的零，而是**引擎根本不具备运行条件**：
> 六格收益率全为 `0.00% / 0 笔`，Δ ≡ 0，**不含任何策略信息**。
> 因此本格**不能**用于"三策略闸门口径是否统一"的决策。

工具：`market_gate_comparison_study.py --semantics live`（已通过 2024H2 六格复现校验）

## 一、为什么不能跑：两个独立的硬约束同时生效

### 约束 1：闸门在 2018 全年无一天开放（预热不足）

```
$ python -c "from market_gate_comparison_study import gate_map; ..."
live==backtest: True   identical days: 2103 / 2103
2018H2 total 124  open 0
open days: []
```

2018 全年 243 个交易日，`blocked_by` **全部**为 `('insufficient_history',)`：

| 项 | 值 | 出处 |
|---|---|---|
| 指数缓存起点 | 2018-01-02 | `cache/index_000001_sh.pkl`（2103 根） |
| 指数第 270 根已收盘日线 | **2019-02-14** | `build_market_gate` 的 `insufficient_history` 判据 |
| 2018 年闸门开放天数 | **0 / 243** | `build_market_gate` 实测 |
| 2018H2 闸门开放天数 | **0 / 124** | 同上 |
| 首个不被 `insufficient_history` 阻断的日 | 2019-02-14 | 同上 |
| 首个 `allows_entries=True` 的日 | **2019-04-08** | 同上（此后还要过 blocker） |

闸门的均线（MA250 等）需要 ≥270 根已收盘日线。指数序列只有从 2018-01-02 起，
到 2018-12-28 仅 243 根 —— **纵使 2018 是单边熊（上证指数收盘全年 **−25.52%**、年内最大回撤 **−30.24%**）、闸门的
"熊市不开仓"意图本该发挥作用，它在此窗口连判据都无法形成**。
最早可评估的窗口是 **2019H2（2019-07-01 起）**，与既有五窗口一致。

### 约束 2：个股缓存同样不足预热（样本 0 只）

即：那 1292 只"回填到 2018"的股票，其历史**起点就是 2018-01-02**（回填请求的开始日），
在 2018-07-01 之前只有 ~120 根日线 ≪ 270。**没有任何一只股票在 2018H2 前有 270 根预热**。

| 候选窗口起点 | "预热满足且窗口内有数据"股票数（估算） |
|---|---:|
| 2018-01-01 | **0** |

样本的 1227 只同量级，说明估算规则与工具的 270-根 规则一致。）

### 结论

**闸门的日历与个股的日历，起点都是"补齐数据的请求边界"（2018-01-02），
都没有真正回填到 2018 年之前的预热段。** 熊市窗口 2018 在数据上不可及 ——
这正是为什么既有五窗口里最熊的那个是 2022，而不是 2018。

## 三、判读：这一格**不支持也不削弱**任何口径

- **不是证据**。Δ≡0 来自"样本空 + 闸门关"，不含策略行为，无法与既有五窗口并列比较。
- 若把它当作"闸门开放 0%、收益 0%"的正例，会重犯 `docs/2026-10-13-闸门对照-2022.md`
  里记录过的错误 —— 但 2022 与它有**本质区别**：2022 的"无闸门"组有 66/100/59 笔真实成交，
  能读出"闸门避开了多少跌幅"；2018H2 的"无闸门"组是 **0 笔**，连对照臂都没有。
- 因此：**"三策略闸门口径是否统一"的决策证据仍是既有五窗口**（2019H2 / 2020H2 /
  2021H1 / 2022 / 2024H2），本次未增加任何一格。

## 五、样本限制（诚实边界）

1. **两侧同时空**：闸门 0/124 且样本 0/5008。任一侧为空就足以使本格无效，此处两者皆空。
2. **根因是数据边界，不是策略或闸门的行为**：指数与个股的缓存起点都是 2018-01-02，
   距 2018H2 不足 270 根预热。**不得**把本格解读为"闸门在 2018 熊市不开仓"的实证 ——
   闸门那些天的关闭原因是 `insufficient_history`，**不是**趋势/波动判据。
3. **1382 只（个股）与 5008 只（整体）**：5008 只全部可读、无损坏；其中仅 1292 只
   回填到 2018，而这 1292 只的 2018 段本身也不够预热。
4. **未联网、未拉数据**（遵守硬约束 1）。若日后要让 2018H2 可用，需把指数与个股
   回填**前推到 2016 年底**（2018-07-01 前 ≥270 根 ≈ 从 2016-12 起），本任务不做。
5. 既有五窗口结果不受影响；本任务的交付是"**如实报告不可用 + 覆盖率数字**"。
