# 用户验收用例

## UAT-1 单股多周期分析

前置：配置数据源并把 `000001.SZ` 放入自选股。

步骤：运行 `python main.py analyze --symbols 000001.SZ --no-notify`。

预期：输出各可用周期的最新价格、MACD 状态、中枢区间、缠论信号和综合评分；单个周期无数据时显示错误但命令不崩溃。

## UAT-2 0 轴金叉扫描

前置：配置 `scan.universe_mode` 和扫描数量。

步骤：运行 `python main.py scan --no-notify`。

预期：只把满足 0 轴阈值的金叉列为候选，按增强评分排序并写入候选池。

## UAT-3 信号推送与去重

前置：启用至少一个通知通道。

步骤：连续两次对同一批已收盘 K 线执行分析。

预期：第一次推送新信号；第二次显示已去重且不重复推送。形成新 K 线和新信号后可以再次推送。

## UAT-4 常驻监控

步骤：运行 `python main.py monitor`，跨越午休和收盘时间观察日志。

预期：交易时段按间隔分析自选股/候选池；午休与非交易时段不抓取分钟线；日线扫描每天只执行一次。

## UAT-5 无密钥安全启动

步骤：使用示例配置且不填真实 Token/Webhook，运行离线测试和 `--no-notify` 分析。

预期：不泄露示例密钥，不因通知未配置而中断分析。

## UAT-6 卖点推送

前置：固定样例在最新已完成 K 线上形成三卖或 0 轴附近死叉，并启用测试通知通道。

步骤：执行单股分析。

预期：卖出评分独立计算并达到阈值，payload 的 `side` 为 `sell`，原因包含对应缠论卖点或死叉证据。
