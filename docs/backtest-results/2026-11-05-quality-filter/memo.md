# 质量过滤 A/B：当前中证 1000 小市值池（2026-11-05）

> 2026-11-06 更新：后续补了“无 open 时按最后价格清算”的修复；2020–2026 修正版基线为 **31.34% / 1.385 / −30.15%**，宽松 27.44%、严格 11.75%。本页保留 2020–2024 原始结果；总归档见 [`2026-11-06-smallcap-research-archive`](../2026-11-06-smallcap-research-archive/README.md)。

## 结论

**在这份样本里，质量过滤没有提升收益或 Sharpe；它只把回撤略微压低，代价是收益和胜率下降。**

- 基线（无质量过滤）：**32.02% CAGR / Sharpe 1.383 / 最大回撤 −30.16% / 交易胜率 73.13%**
- 宽松质量（ROE≥8、ROA≥4）：**29.66% / 1.212 / −28.35% / 62.17%**
- 严格质量（ROE≥15、ROA≥10）：**11.41% / 0.588 / −35.54% / 47.71%**

所以：**不能因为“加了质量过滤”就认为策略会更强。** 这轮证据反而说明，在当前中证 1000 小市值池里，质量过滤更像“减仓/降波动”，不是 alpha。

**重要前提：当前中证 1000 是 2026-11-05 快照，不是历史 PIT 成分；基线 32% CAGR 有选择偏差，不能当作真实历史收益。** 本报告只用于比较同一池子内的边际效果，不用于对外宣传。

## 解读

1. **质量过滤不是收益引擎。** 它剔除了高杠杆、负现金流、高商誉等风险，但也可能剔除高弹性小市值；在这段样本里，后者贡献更大。
2. **严格质量过滤导致集中度上升。** 通过数太少，持仓从 30 降到约 11， idiosyncratic risk 上升，回撤反而更大。
3. **2024 年差异最大。** 基线 +28.88%，宽松 +9.31%，严格 +0.14%；质量过滤错过了 2024 年的一部分小市值行情。
4. **当前池选择偏差是最大噪音。** 2026 年才进入中证 1000 的股票，在 2020–2024 往往已经是赢家；基线的高收益不能外推。质量过滤的边际结论也只在“这个当前池”内成立。
5. **没有调阈值。** 宽松/严格是预先设定的两组，不是扫出来的最优参数；不要因为结果不好再改成 10/5 或 12/6。

## 决策

- **不把质量过滤加入现有股票策略的生产候选层。**
- 不用这轮结果证明“质量因子无效”；它只证明：**在当前中证 1000 小市值池、这组门槛、这段样本里，质量过滤没有边际收益。**
- 如果继续研究，优先级是：
  1. 补历史 PIT 中证 1000 + 退市池，先消除选择偏差；
  2. 把质量做成**连续打分/风险惩罚**，而不是硬过滤，观察是否改善回撤而不砍收益；
  3. 预注册样本外，再决定是否进入研究组合。
- 不做：在这份样本上继续调 ROE/ROA 阈值凑结果。
