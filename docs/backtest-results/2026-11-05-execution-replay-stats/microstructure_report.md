# ETF 微观结构数据闭环（V5）

- 数据：Sina 原始日线 OHLCV + Eastmoney 历史单位净值
- 覆盖：47/47 只当前池 ETF；原始行情 2011-12-09 → 2026-11-04；净值/溢价统计以可用交集为准
- 脚本：`quant-python/signal_system/etf_microstructure.py`
- 本地数据：`D:/tmp/etf_microstructure/`（`premium_discount.csv`、`spread_proxy.csv`、`half_spread.csv`）
- 结论：**溢价/折价很小；高低温差 spread 代理明显大于 5bp，且基准比 TSMOM 更敏感。**

## 1. 溢价/折价

- 对这 47 只流动性较好的 ETF，**溢价/折价不是主要成本**；极端值很少。
- 溢价/折价是“价格相对净值”的估值差，**不是**在市场价之上再加一次成本；回测用市场价成交时已经包含了它。
- 可用途：诊断入场日是否处于极端溢价/折价；若要做“溢价过滤”是策略变体，需单独预注册，不能直接加。

## 2. 高低价差代理（Corwin-Schultz）

| 指标 | 往返 spread | 单边 half-spread |
|---|---:|---:|
| 均值 | 0.486% | 0.243% |
| P50 | 0.114% | 0.057% |
| P95 | 1.860% | 0.930% |
| P99 | 2.963% | 1.482% |

- 这是**日线高低价估计量，不是盘口报价**；它会受日内波动影响，通常偏大。
- 基准的 5bp 单边滑点约等于代理的 P50（5.7bp），但**明显低于 P95/P99**；尾部行情下实际成本可能远高于 5bp。
- 因此把它作为**压力上界/诊断**，不要当成精确成交价。

## 3. 用经验 spread 面板重跑压力

同一信号、同一区间，按日按标的套用 `half_spread.csv`：

| 资金 | 策略 | baseline CAGR / Sharpe / DD | 经验 spread CAGR / Sharpe / DD | 变化 |
|---:|---|---:|---:|---:|
| 250k | ETF 基准 | 9.87% / 1.20 / −10.19% | **8.32% / 1.02 / −10.88%** | −1.55pp / −0.18 |
| 250k | TSMOM 3 资产 + 10% vol | 9.21% / 1.15 / −12.48% | **9.07% / 1.14 / −12.67%** | −0.14pp / −0.01 |
| 500k | ETF 基准 | 9.92% / 1.20 / −10.20% | **8.34% / 1.03 / −10.90%** | −1.58pp / −0.17 |
| 500k | TSMOM 3 资产 + 10% vol | 9.25% / 1.16 / −12.52% | **9.10% / 1.14 / −12.72%** | −0.15pp / −0.02 |

- 基准换手 72–73x，且持有卫星 ETF；经验 spread 把 CAGR 拉到 8.3% 左右，Sharpe 约 1.02。
- TSMOM 只交易 3 只高流动性 ETF、换手 13.6x，几乎不受影响。
- 这解释了为什么“5bp 滑点”对基准偏乐观：不是每天都很贵，而是高换手放大了尾部价差。
- **注意**：经验 spread 场景叠加在 5bp 基础滑点上，可能双重计算；它是偏保守的上界，不是净成本校准。真实成本应等前向纸面账本的成交记录。

## 4. PIT 退市池与部分成交

- **SSE 历史 ETF 规模表可用**（`fund_etf_scale_sse(date=...)`）：2020/2021/2022/2023/2024/2025 六个快照的并集为 640 个代码，其中 66 个不在当前全市场列表（含退市、合并、改名，需逐一核验，不能直接都算退市）。
- **样例验证**：`510070` 有 2,148 行 Sina 原始行情和 361 行 NAV；`510110` 有 2,893 行原始行情和 1,095 行 NAV。说明上海退市/老 ETF 的行情和净值**可以补齐**。
- **SZSE 历史列表不可用**（`fund_etf_scale_szse` 解析失败）；当前 47 只池子都是当前上市标的，**完整 PIT 仍未接入回测**，幸存者偏差未消除。
- **部分成交/队列数据不可用**；50% fill-ratio 仍是假设，不是实测。
- 下一步若要关闭 V4：先补齐 SSE 历史池并核验代码状态，再解决 SZSE 历史列表；在此之前，回测的当前池不能称为 PIT。

## 5. 结论

1. V5 的溢价/折价已可用历史数据验证：对本池很小，不是第一成本。
2. 盘口价差仍无真实 quote；高低价代理显示尾部成本显著高于 5bp，基准对执行成本敏感。
3. 若继续推进实盘，优先解决 **PIT 退市池 + 真实盘口/成交样本**；不要用代理 spread 的均值去“校准”一个更好看的数字。
4. 前向纸面账本已启动，后续用实际记录替换这些假设。
