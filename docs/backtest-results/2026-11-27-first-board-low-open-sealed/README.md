# 首板低开：涨停改成「收盘封住」后重跑（2026-11-27）

状态：研究回测，不接生产、不自动交易。规则一条没改，只改了一处和写下来的规则不一致的代码。

## 结论

- 原来的涨停判定恒为真：`high >= close - 0.005` 在日线上永远成立，所以「首板」实际是「当天涨幅到了涨停幅度」，摸到涨停又回落的板也算。改成「涨幅够 且 收盘价 = 当日最高价」之后，全样本信号 331 → 311（2020 起 277 → 260），成交 257 → 244（2020 起 219 → 208）。
- 账本口径的 1/3 上限账户（2020-01-02 → 2026-10-30）：总收益 +174.9% → +170.1%，年化 15.97% → 15.67%，最大回撤 −23.29% → −21.47%，Sharpe 1.080 → 1.085，单笔均值 +1.46% → +1.56%，盈亏比 1.676 → 1.744，胜率 50.7% → 50.5%。
- 结论不变：仍然显著好于等权基准（同期年化 12.07%）。收益略降、回撤和波动一起变小。
- 注意：被去掉的板**不是**一批烂单。它们在旧回测里成交过的 15 笔单笔均值 +0.44%（2020 起 13 笔 +0.40%），2020 起那 17 个信号次日「开盘→再下一日收盘」均值也只有 −0.61%。所以这次变化主要是账户路径变化（不再被没封住的票占住仓位），不是把亏损单剔掉了。
- 年度分布动了：2025 年 +3.5% → −1.8%，2026 年 +16.8% → +24.7%，年化几乎没动是这两年的差互相抵消。逐笔原因见下。
- 下游三项预注册检验（混合腿、ST、开盘成交量）和四个聚宽策略、回调 V0–V5、三槽对比重跑后结论全部不变。

### 容差怎么定的

前复权价算不出精确涨停价，只能估。用三个口径在同一份面板上数「涨幅到了涨停线」的日线（5,096 只，2019 起 110,666 根）：

| 封住条件 | 涨停根数 |
| --- | --- |
| 收盘 == 最高（严格） | 107,989 |
| 相对误差 1e-9 | 107,989 |
| 绝对误差 ≤ 0.005 | 108,024 |

绝对容差多认 35 根；落在 (0, 0.005] 区间的一共 39 根，基本是四舍五入和前复权缩放造成的一个「调整后 tick」。三种口径下 s1 的信号集合完全一致（311 个），所以取严格相等。
