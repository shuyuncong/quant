# PIT 全 A 版“质量 A/B baseline”（2020–2026）

## 结论

**质量 A/B baseline 的 31% 也不稳健。**

把股票池从“2026 中证 1000 快照”换成 **PIT 全 A + 237 只退市股**，其余规则不变（100→30 最小市值、月度、无质量过滤、无行业 cap、5bp 滑点）：

| 指标 | 当前快照 baseline | PIT 全 A 版 |
|---|---:|---:|
| CAGR | 31.05% | **6.44%** |
| Sharpe | 1.369 | **0.399** |
| 最大回撤 | −30.16% | **−48.52%** |
| 交易胜率 | 74.42% | 60.53% |
| 盈亏比 | 2.837 | **0.899** |
| 期末权益 | 1,601,365 | 387,988 |
| 平均持仓 | 30.01 | 29.84 |
| 年均换手 | 2.88x | 5.39x |

**收益从 31% 掉到 6.4%，回撤从 30% 扩大到 48.5%，盈亏比跌破 1。**  
这不是“质量过滤”的问题，而是 baseline 本身依赖当前成分池和幸存者偏差。

## 设置

- 股票池：PIT 全 A 5,059 只（4,817 当前上市 + 237 只有行情的退市股 + 少量新列）；
- 选股：每月末，按 PIT 流通市值取最小 100 只，再取其中最小 30 只；
- 质量过滤：**无**；
- 行业 cap：**无**（与质量 baseline 相同）；
- 调仓：月末信号，下一交易日开盘；
- 成本：佣金 3bp（最低 5 元）、卖出印花税 10bp、滑点 5bp；
- 约束：整手、T+1、涨跌停/停牌跳过；
- 区间：2020-01-02 → 2026-10-30。

## 关键修复

第一次跑 PIT 版时，平均持仓约 52 只，而不是 30 只。原因是退市/停牌后没有 open，卖出失败，持仓不断累积，净值被“僵尸持仓”污染。

现在改为：目标卖出时若没有 open，按最后可用价格清算。修正后平均持仓 **29.84**，结果才是可比的 6.44% / 0.399 / −48.52%。

## 解读

1. **31% 不是选股能力，主要是池子。**  
   同一套“100→30 最小市值、月度、无质量过滤”规则，换成 PIT 全 A 就只剩 6.44%。

2. **回撤反而更大。**  
   当前快照池没有退市股，PIT 池有；小市值退市前的下跌会真实进入净值，最大回撤扩大到 −48.52%。

3. **盈亏比 0.899。**  
   胜率 60.5%，但平均盈利小于平均亏损；靠“赢多输少”而不是“赢大输小”，质量很差。

4. **质量过滤仍然没证明有用。**  
   之前在当前快照上，宽松 27.64%、严格 11.75%，都低于 baseline 31.05%；在 PIT 池上也没有理由假设硬过滤能把它变成稳定策略。

## 决策

- **不投产。**
- 不再用当前中证 1000 快照的 31% 作为预期。
- 不再为这个 baseline 买历史 PIT 数据；PIT 全 A 版已经把它打到 6.44% / −48.52%。
- 如果还要继续，方向应是“新信号/新逻辑”，不是继续调市值、行业 cap 或止损。
