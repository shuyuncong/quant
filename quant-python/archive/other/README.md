# Archived legacy scripts

This directory contains historical, non-production strategy and AI-generated scripts formerly stored under `quant-python/other/`.

Repository search found no runtime, Web, Docker, CI, test, or documentation caller for these files. They are retained here only for manual reference and are not part of the supported application or deployment image.

The supported runtime is `quant-python/web` plus `quant-python/signal_system`. These archived files may depend on uninstalled packages such as `backtrader`, TA-Lib, Tushare, or yfinance and may contain historical placeholder configuration. Do not import them into production code.
