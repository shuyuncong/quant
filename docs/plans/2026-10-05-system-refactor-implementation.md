## 一致性与恢复

- 任务冻结股票范围、持仓成交快照和有效策略配置；仅保存规则配置，连接信息和凭据在执行时解析。
- 同一轮分析按 K 线实际完成时间截断，日线按 15:00 截断。之后取到的收盘 K 线不能进入早先的盘中快照。指数上下文也按该时点截断。
- 年线和底背离沿用现有指标池的前复权日线；MACD 通知沿用原不复权行情。报告标注口径，持仓成本按同日复权比例换算比较。
- 年线规则只包含当前六条件回踩，不替换为旧研究脚本中的突破路线。趋势退出保持当前 `apply_to_signal_types` 范围。
- 股票报告先保存策略计算，再分别保存两个 AI 阶段。技术分析重试会使综合结论重新生成，避免使用旧综合意见。
- 分析、扫描和回测后台重任务采用单工作队列的数据库锁；AI 阶段另有限流锁，为调度和读取接口保留连接。
- 新定时计划使用严格交易日历。日历无法确认交易日时不凭“周一至周五”补造交易日。
- 股票池和回测继续沿用 Python 本地文件/SQLite 的既有分工，本轮未迁移全部数据存储。

## 明确边界

1. 回测以本地缓存覆盖范围为样本，不具备完整历史退市/ST 数据；前复权理论成交没有逐笔复原送转股份。MACD 在除权附近可能与不复权实时通知出现日期差异。实时入池的市值、流动性和市场闸门未纳入历史筛选，报告已明确说明。
2. 旧持仓是期初快照，不能据此推断历史买入日期、真实可用现金或完整盈亏。期初持仓的可卖量按已结算数量处理，之后登记的买入执行 T+1；校正操作用于修正账面快照，实际卖出应登记减仓/清仓。
3. 当前成交列表提供最近 50 笔，数据库保留全部成交。AI 每股取最近 50 笔并额外保留当日全部成交用于风控。
4. 重试复用原报告快照及已完成阶段；暂不跨独立分析任务复用 LLM 内容。每次计划都会生成独立执行记录。
5. 旧路由保留兼容页面，没有强制重定向。任务父记录继续使用既有状态字段，部分失败由逐股状态和父任务说明表达。
6. 全市场回测采用串行、有检查点的本地执行；尚未做完整 5000 只股票压力测试。大型报告可在本地输出目录获取完整 JSON。

本轮没有修改同时进行中的 `backtest_macd_divergence.py`、`ranking_study.py` 及其他策略研究改动。重构提交仅包含上述功能及相关文档，未推送远程。
