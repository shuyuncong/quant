# UAT 用例

## UC-1 结果查看
前置：output 目录存在至少一份分析 JSON。
步骤：打开结果页，筛选类型/时间，进入详情。
预期：列表与详情展示正确；有模型配置时详情含 AI 解读。

## UC-2 策略配置
步骤：修改缠论/MACD 参数并保存，重新触发 analyze。
预期：保存成功提示；新分析使用新参数（结果字段可见）。

## UC-3 推送配置与测试
步骤：填写微信 webhook 并保存，点击“发送测试通知”。
预期：测试结果回显 success/failed；失败原因可见。

## UC-4 模型配置
步骤：新增 OpenAI 兼容配置（名称/base_url/model/key），点击测试连通性。
预期：连通性结果正确；配置回显时 key 脱敏。

## UC-5 定时配置
步骤：设置每日扫描 15:30 + 30 秒监控间隔，启用；等待触发。
预期：任务页出现运行记录；下次运行时间正确；仅交易日开关生效。

## UC-6 股票池文本导入
前置：output 目录无要求。
步骤：粘贴多只股票（混合分隔符），预览确认。
预期：解析结果正确，确认后入库，重复代码被合并。

## UC-7 股票池图片导入
前置：已配置支持视觉的模型。
步骤：上传截图，等待识别，在确认页勾选/修改，确认。
预期：候选列表合理，确认后入库；未配模型时给出明确提示。

## UC-8 手动触发
步骤：结果页点击“立即分析”并选择自选股/指定股票。
预期：任务运行中状态可见，完成后结果出现在列表顶部。
