# 测试计划

## 单元测试

- MACD：长度、数值有限性、标准金叉、0 轴阈值内外、死叉。
- 周期转换：1 分钟到各分钟周期、60 分钟到 120 分钟的 OHLCVA 聚合、午休不跨桶、时间戳语义和未完成尾桶剔除。
- 缠论：包含方向与翻转、严格分型、同类极值替换、笔最小间隔、中枢结束/扩展、一/二/三类买卖点及反例。
- 事件指纹：相同股票/周期/类型/K 线时间一致，不同 K 线不同。
- 交易时间：正式交易日历、节假日、两段交易时间、午休、周末、错过任务后的补跑。
- 逐根回放：每增加一根已收盘 K 线重新计算，已确认事件不可改变，不得读取未来行。
- 评分：各加减分项、缺失周期、冲突信号、阈值边界和稳定排序。
- 独立验证买入与卖出评分均能达到推送阈值；卖点 UAT 不依赖金叉条件。

## 集成测试

- 使用内存假行情提供方分析多个周期，生成结构化报告。
- 相同报告执行两次，第二次不产生重复事件；多通道部分成功只重试失败通道。
- 某一周期抛出异常时，其余周期仍返回。
- 通用 Webhook 使用 mock 验证 schema、认证头、幂等键、超时、5xx 和重试。
- 候选池验证 TTL、容量、每日分数更新、停牌/退市清理。
- 验证全市场历史回填可中断续跑、成功状态会重新校验本地缓存、股票池变化与上市不足 120 日股票不虚增或阻塞覆盖率、批量日线只追加有效 OHLC；复权不一致周期被拒绝，Tushare `none` 可用，数据源切换与除权触发重建。

## 回归与命令验证

- `python -m unittest discover -s tests -v`
- `python -m compileall -q .`
- 使用本地 CSV/合成数据执行 `analyze --no-notify`，不访问网络。
- 配置文件加载、环境变量替换、相对路径基于配置文件所在目录解析。

## 边界

- 少于 MACD 慢周期或少于成笔数量的数据。
- 停牌零价快照、零成交量、重复时间戳、倒序数据、NaN。
- outbox 大批量投递时只领取当前发送项，避免后半批租约提前过期。
- Webhook 5xx、超时、非 JSON 响应。
- SQLite 已存在相同唯一键。
- 首次启动存在陈旧历史买点、最新 K 线未收盘、除权日价格跳变、长期停牌和上市初期数据不足。
