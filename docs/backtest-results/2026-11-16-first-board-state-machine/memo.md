# 首板低开：市场走势状态机（2026-11-16）

## 结论

**状态机没有稳定的可交易边际。** 全样本里“下跌状态”反而最好（均值 +1.68%/笔）、“上涨状态”最差（+0.12%/笔），但 2025–2026 下跌状态转为 -0.38%。唯一在设计和留出段都改善的是「跳过 turn_down」，但只有 7/4 笔样本，bootstrap P(Δ>0)=0.946，低于 0.95 的验收线。

## 状态定义（固定，不调参）

市场代理：等权主板+创业板日线净值。MA20、MA60、MA20 五日斜率。

- `up`：close > MA20 > MA60 且斜率 > 0
- `down`：close < MA20 < MA60 且斜率 < 0
- `turn_up`：close > MA20、斜率 > 0，但 close ≤ MA60
- `turn_down`：close < MA20、斜率 < 0，但 close ≥ MA60
- `range`：其余

信号日 T 只使用 T-1 及以前的数据。

`skip_turn_down` 的 bootstrap：P(Δ>0)=0.946，95% 区间约 [-0.00002, +0.00039]，跨 0，刚好低于 0.95 验收线。改善主要来自避开 7 笔 turn_down，样本太少。

## 判断

- **不能直接上线**：状态效应在留出段反转，且关键状态样本只有个位数。
- **可以保留为风险提示**：turn_down（高位转弱）是唯一在两个阶段都为负的状态；如果要用，只作为“暂停开新仓”的软开关，不作为收益增强。
- **不建议按状态选方向**：`skip_down` 是最差的规则（+30.7%），说明“趋势向上才做多首板低开”在这个样本里是反向的。
