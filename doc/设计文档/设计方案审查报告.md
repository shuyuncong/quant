## 2. 关键问题（Critical）

### ❌ 问题1: 仓位管理严重偏离

**知识星球标准**:
> 同时买三个股票，每一个股票持有25%基本仓位，保留25%机动资金

**当前设计**:
```yaml
position:
  max_single_position: 0.25  # 单只25%
  reserve_cash_ratio: 0.25   # 机动25%
```

**问题**:
- 设计中是"最大25%"，但没有强制"每只25%"
- 缺少"3只股票"的硬性限制
- 没有区分"基本仓位"和"机动资金"的概念

**修正建议**:
```yaml
position:
  stock_count: 3              # 固定3只股票
  base_position_per_stock: 0.25  # 每只基本仓位25%
  mobile_cash: 0.25           # 机动资金25%
  max_stocks: 4               # 最多4只（允许临时超配）
```

---

### ❌ 问题2: 完全缺失做T策略

**知识星球核心**:
> 做T技巧跟资金管理必须搭配使用，主要思路还是顺势而为

**当前设计**:
- ❌ 没有做T模块
- ❌ 没有区分"基本仓位"和"机动仓位"
- ❌ 没有"正T"和"反T"的逻辑

**修正建议**:
需要新增 `TradingModule` 模块：
- 上涨趋势：正T（底背离加仓，顶背离减机动）
- 下跌趋势：反T（顶背离减基本仓，回落买回）
- 震荡市：机动资金高抛低吸

### ⚠️ 问题3: 背离检测算法不精确

**知识星球标准**:
> 相邻两个MACD红/绿柱子围成的**面积**，后一个比前一个小

**当前设计**:
```python
# 只比较了峰值点，没有计算面积
price_lower = recent_price[last_trough] < recent_price[prev_trough]
indicator_higher = recent_indicator[last_trough] > recent_indicator[prev_trough]
```

**问题**:
- 只比较了峰值，没有计算柱子面积
- 面积 = 高度 × 持续时间

**修正建议**:
```python
def calculate_macd_area(hist, start_idx, end_idx):
    """计算MACD柱子面积"""
    area = 0
    for i in range(start_idx, end_idx):
        if hist[i] < 0:  # 绿柱
            area += abs(hist[i])
    return area

# 比较面积
prev_area = calculate_macd_area(hist, prev_start, prev_end)
last_area = calculate_macd_area(hist, last_start, last_end)
divergence = (price_lower and last_area < prev_area)
```

## 3. 重要问题（Warning）

### ⚠️ 问题4: PE 阈值设置不合理

**知识星球标准**:
> PE<17倍为优，<30倍可接受

**当前设计**:
```yaml
max_pe: 30  # 最大30
```

**问题**:
- 没有区分"优选"和"可接受"
- 应该有优先级排序

**修正建议**:
```yaml
fundamental:
  pe_excellent: 17    # 优选
  pe_acceptable: 30   # 可接受
  # 评分: PE<17 得3分，PE<30 得1分
```

---

### ⚠️ 问题5: 换手率范围偏宽

**知识星球标准**:
> 日均换手率在1%-3%的股票，这种股票通常就是主力打压吸筹阶段

**当前设计**:
```yaml
min_turnover_rate: 1
max_turnover_rate: 5  # 偏高
```

**问题**:
- 上限5%偏高，知识星球推荐1-3%
- 5-10%是"低位放量滞涨"，应该单独处理

**修正建议**:
```yaml
volume:
  normal_turnover: [1, 3]      # 正常范围
  accumulation_turnover: [5, 10]  # 吸筹阶段（特殊信号）
  danger_turnover: 20          # 危险阈值
```

---

### ⚠️ 问题6: 缺少"空头陷阱"识别

**知识星球核心**:
> 年线低位向上走，股价短期跌破年线后并没有深跌就开始站稳，比如出现底背离

**当前设计**:
- 有年线判断
- 有底背离检测
- ❌ 但没有"空头陷阱"的综合判断逻辑

**修正建议**:
```python
def detect_bear_trap(df):
    """
    识别空头陷阱

    条件：
    1. 年线向上
    2. 短期跌破年线
    3. 快速收回（3-5天内）
    4. 出现底背离
    """
    ma250_slope = calculate_slope(df['ma250'])

    if ma250_slope <= 0:
        return False

    # 检查是否短期跌破年线
    recent_break = check_recent_break_below_ma(df, days=5)

    # 检查是否快速收回
    quick_recovery = check_quick_recovery(df, days=5)

    # 检查底背离
    divergence = detect_bullish_divergence(df)

    return recent_break and quick_recovery and divergence
```

## 4. 建议改进（Info）

### 💡 建议1: 增加量价关系判断

**知识星球标准**:
- 放量上涨：持股
- 缩量上涨：减仓
- 放量下跌：观望
- 缩量下跌：加仓

**当前设计**: 只有简单的"放量"判断

**建议**: 增加完整的量价关系模块

---

### 💡 建议2: 增加"战略买入点"评分

**知识星球核心**:
> 战略买入点：在大的上涨趋势中，中期调整中没有有效跌破长期趋势线的点位

**建议**:
- 战略买入点应该是最高优先级
- 评分应该显著高于普通信号

---

### 💡 建议3: 止盈策略需要分级

**知识星球标准**:
- 波段盈利20%~30%可考虑减仓
- 翻倍以上或出现顶背离全面减仓

**当前设计**: 只有一个30%止盈

**建议**:
```python
profit_levels = {
    0.20: 'reduce_mobile',      # 20%减机动仓
    0.30: 'reduce_base_partial', # 30%减部分基本仓
    1.00: 'reduce_all'          # 翻倍全面减仓
}
```
